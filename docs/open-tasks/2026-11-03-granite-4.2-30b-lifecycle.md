## The defect (TDD)

**RED:** `test_granite_dense_selfcheck`'s tool round-trip failed on real
weights. The model generated an explanation (`## Example 2 …`) that degenerated
into malformed XML with repeated `</parameter>`, and no tool call parsed.

**Investigation (wrong hypotheses kept in the trail):**

1. *Prompt-text mismatch.* `RenderGraniteConversation` emits the tool
   `parameters` JSON compactly and appends a trailing newline after
   `<think></think>`, where `chat_template.jinja` (via Python `tojson`) uses
   spaced JSON and no trailing newline. Real, but not the cause.
2. *Tokenizer mismatch.* `arrow_tokenizer_encode` does not literal-match the
   non-special added token `<tool_call>` (it only matches `special: true`
   tokens); `tokenizer_parity` on the full reference prompt therefore reports a
   first diff at id 115. This is **not** the prompt path: the granite codec
   splits its sentinels (`AppendGraniteChatIds`) and injects `<tool_call>` by
   lookup, so the engine prompt is fine. Verified the engine prompt decodes to
   the source tool call under the strict path.
3. **External oracle.** Ran the BF16 checkpoint itself on CPU and fed it the
   exact reference ids. It emitted
   `\n<tool_call>\n<function=get_weather>\n<parameter=city>\nParis\n</parameter>\n</function>\n</tool_call>\n<|im_end|>`.
   The converted model on the **auto/TC** path, fed the *same* ids, emitted
   `_with_n_comprehension_n_comprehension…`. So it was numeric, not framing.

**Root cause:** the NVFP4 tensor-core path quantizes activations to E2M1 with
E4M3 block scales; this checkpoint's long tool/template prompt drives
activations past that range, the TC prefill clamps, and the decode collapses.
The strict FP16-activation path (`FastMathMode::kOff`) reproduces the source
token-for-token. This is the same class and the same remedy as the
`granite-switch` sibling.

**Fix:** pin `FastMathMode::kOff` in `Granite42_30BModel::Infer` (the per-GPU
policy is still consulted, so the model-independence guard's contract holds).
GREEN: SelfCheck Paris ×3 bit-exact (`logits_hash c165e80fde6401cf`, top-1
12366), FSI 3/3, CODE 3/3, DET 3/3 deterministic, tool round-trip
`get_weather {"city":"Paris"}`.

## Residuals (non-blocking)

  framing.

  action taken here.
