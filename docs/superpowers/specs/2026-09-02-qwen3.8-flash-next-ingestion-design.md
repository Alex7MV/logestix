# Qwen3.8-Flash-Next (qwen4_exp MoE) — Design

Date: 2026-09-02
Status: approved design, pending implementation plan
Branch: `feat/model-Qwen3.8-Flash-Next`

## Overview

Ingest Qwen3.8-Flash-Next (`Qwen4ExpForConditionalGeneration`, model_type
`qwen4_exp_text`) into the logestix monorepo following the 8-step Model
Ingestion Protocol. Approach A (approved): extend the Qwen3.5-35B-A3B MoE
pipeline — converter/loader/kernels reuse the bit-exact TC-batch etalons;
net-new components are implemented only where the architecture is genuinely
new (GatedResidual hyper-connections, QSA indexer, PLE n-gram lookup).

Source checkpoint (read-only): `/mnt/llm_models/models/Qwen3.8-Flash-Next`
(336 GiB BF16, 131 safetensors shards). HF reference:
`transformers/models/qwen4_exp/modeling_qwen4_exp.py` (v5.16+), formulas
pinned below for bit-exact implementation.

Performance stance (operator decision): correctness first — working SelfCheck
("The capital of France is" → "Paris") at the maximum achievable speed;
100+ tok/s tuning iterations follow after the pipeline is green. Traffic per
token is ~60× that of Qwen3.5 (512 experts × top-10 × 48 layers ≈ 281 GiB
NVFP4 touched per token), so 100 tok/s is a tuning goal, not a correctness gate.

## Pinned HF formulas (bit-exact contract)

- **GatedResidual** (`Qwen4ExpTextGatedResidual.forward`):
  `mixed = mean_c( sigmoid(up(silu(down(norm(x))/hc_count))) ⊙ norm(x)_c )`;
  `injection_weights = 2·sigmoid(block_inject(norm(x))/hc_count)`;
  layer output: `hyper_input + (branch_out ⊙ w).flatten(-2)` (scatter over 4
  branches). `hc_norm` is group-RMSNorm over 10240 with group_size 2560,
  `1 + weight` centering.
- **Gated DeltaNet**: `g = -exp(A_log.float()) · softplus(a.float() + dt_bias)`;
  `beta = sigmoid(b)`; QK heads repeat_interleave(3) to 48 V-heads;
  RMSNormGated with z-gate (`output_gate_type=sigmoid`); causal conv1d k=4
  (groups=conv_dim), incremental conv state on decode.
- **QSA indexer**: per 4-token block — pooled keys (float mean → k_layernorm →
  RoPE at block start), score = relu(q·k).sum/√128, top-512 blocks; residual
  tail tokens (< 4) appended unmasked; final mask = causal ∧ selected.
  Degenerate fast-path: context ≤ budget → full causal mask (no top-k).
- **Attention output gate**: `q_proj` produces HD×2 per head; output = o_proj(
  attn ⊙ sigmoid(gate)) — same convention as Qwen3.5.
- **Router**: softmax(fp32) → top-10 → renorm (`norm_topk_prob=true`).
- **PLE** (`Qwen4ExpTextPLELayer.forward`): gate =
  `sign(Σ_c key_c·query_c / √2560) · √(|Σ| clamped 1e-6)`; value scaled by
  sigmoid(gate); norm_conv; dilated depthwise short-conv (k=4, dilation=3,
  state 9 rows); output added to hidden states BEFORE the attn hyper-connection.
  Hash: splitmix64-based layer multipliers + per-head prime vocab sizes
  (`_find_nth_prime_after(20'000'000-1, k)`) — computed at conversion, stored
  in `ple/meta.arrow`.

Output layout (format tag `"logestix-qwen38flashnext"`; all paths through
`lsx_model_metadata(rel)` / `lsx_model_metadata_root()` — zero hardcoded paths):

```
logestix/
  model.index.json          # extended passport: hc_*, indexer_*, ple_*
  pinned/global.arrow       # embed_tokens NVFP4
  pinned/lm_head.arrow      # lm_head NVFP4
  pinned/layer_<N>.arrow    # dense per-layer: GDN (in_proj_qkv/z/a/b, conv1d,
                            #   A_log, dt_bias, norm, out_proj), QSA (q/k/v/o,
                            #   q_norm/k_norm, indexer), hc (hc_norm FP16,
                            #   down/up/block_inject NVFP4), MoE norms;
                            #   layer_2 additionally carries PLE projections
                            #   (key/value_proj, norm_key/query/conv, conv1d)
  router/layer_<N>.arrow    # mlp.gate.weight BF16 (never quantized)
  shared/layer_<N>.arrow    # shared expert NVFP4 + FP16 scalar gate
  experts/layer_<N>/exp_<E>.arrow   # 48 × 512 files, NVFP4 w1/w3/w2
  ple/shard_<S>.arrow       # 128 × [2500012,160] BF16 — mmap-only, never in VRAM
  ple/meta.arrow            # layer_multipliers, ngram_heads_offsets/sizes,
                            # per-head prime vocab sizes
  mtp/...                   # stored-not-applied subtree
```

Quantization policy (extends `qwen_tensor_is_nvfp4`):
- NVFP4: embed, lm_head, all attention/GDN/hc-down/up/block_inject projections,
  expert w1/w3/w2, shared expert, PLE key/value_proj.
- High precision, never quantized: all RMSNorm weights (incl. group-RMSNorm
  hc_norm), router, shared_expert_gate, PLE norm_*, conv weights.
- A_log/dt_bias stored FP16, upcast FP32 at load (HF uses `.float()`).

Integrity: `VerifyAllTensorReads`; coverage = {language_model, mtp,
visual (counted skip), ple (partitioned)}; layer contiguity 0–47; geometry
cross-check vs frozen constants; VRAM profile in manifest. Per-tensor GPU
quantization reuses `safetensors_gpu.cu` kernels. Expected output ~78 GiB
(57.4 experts + ~7 dense NVFP4 + 95.4 PLE mmap + fp16 norms).

## Loader, memory, LRU cache (protocol step 3 context)

New files:
- `libs/lsxcommon/include/lsxcommon/qwen_moe_exp_load.h` + `src/qwen_moe_exp_load.cpp`
- `libs/lsxcommon/include/lsxcommon/qwen_moe_expert_cache.h` (extension of the
  existing `qwen_moe_expert_cache.h` LRU device-slot cache to 512 experts)

Resident on GPU after load (~14.5 GiB): embed 0.6 + lm_head 0.6 + dense ~4.5
+ router 0.06 + shared ~1.2 + PLE projections 0.06 + scratch/KV/QSA ~7 GiB.

LRU routed-expert cache: slot = 600 MiB NVFP4 w1/w3/w2 arena; budget ~16
slots (9.6 GiB) computed by `Qwen38FlashNextStrategy : MoEStrategy` from free
VRAM (TuningBounds pattern). Host-side bookkeeping (`CacheLookup`/`CacheInsert`
inline helpers, hit/miss counters) unit-testable without CUDA
(`test_kimi_moe_expert_cache` pattern).

PLE mmap: 128 shards opened `mmap(PROT_READ)` at Load; lookup
`ple_lookup(token, head)` touches ~2 KiB per token — OS page cache + pinned
bounce ring (256 rows = 80 KiB) feeds the ple-inject kernel. Hash arithmetic
is pure integer host/device code.

Pinned staging: reuse of the qwen ring machinery
(`LoadQwenMoePinnedWeights`), BF16→FP16 in-place for dense parts, per-layer
device arenas, strict errors on missing layer files / malformed tensors.
E4M3/E8M0 scale decode identical to the qwen etalon.

## CUDA kernels (protocol steps 5–6)

New file `libs/lsxcommon/src/qwen_moe_exp_inference.cu` → OBJECT library
`lsxcommon_qwen_moe_exp_cu` (Blackwell 120/121-real, `--extended-lambda`,
`-fmad=false`), linked PUBLIC into `lsxcommon`.

1. `hc_gated_residual_kernel` — GatedResidual (group-RMSNorm → down → silu/4
   → up → sigmoid → mean; + block_inject variant). 2 launches per layer.
2. `hc_inject_scatter_kernel` — `hyper_input + (branch_out ⊙ w)` over 4 branches.
3. Gated DeltaNet decode — reuse `qwen_gated_delta_kernel` (runtime
   parameterized `QwenTopology`) with 16×128 QK / 48×128 V, repeat 3; FP32
   `g` math replicated bit-exact via `qwen_device_math.h`.
4. `qsa_indexer_decode_kernel` — MQA key cache [T,128], 4-token block pooling,
   relu-score, top-512, selected-token mask; shared-memory RMW writes only
   from thread 0 behind hard `__syncthreads()` (protocol step 6, etalon
   `full_attn_softmax_kernel`); fast-path full-causal for ctx ≤ 2048.
5. QSA full attention — reuse `full_attn_softmax_kernel` + sigmoid output
   gate, GQA 24:2, rotary_dim 64, mask = causal ∧ selected.
6. Router top-10 — parameterized `qwen_moe_router_topk_kernel`
   (512 experts, top-10, thread-0 selection, softmax→top-k→renorm).
7. Routed FFN — reuse `RunQwenNvfp4Gemm` TC-batch chain unchanged (slots
   10/token), shared-gate combine reused.
8. `ple_lookup_hash_kernel` (host mmap row → pinned ring) +
   `ple_inject_kernel` — gate formula, sigmoid·value, norm_conv, dilated
   short-conv with 9-row incremental state.
9. `hc_mixer_kernel` — global mixer (GatedResidual without block_inject),
   fused with final norm position in the epilogue.

Protocol invariants: single end-to-end `cudaStream_t` per generation, no
`cudaDeviceSynchronize` in the loop (final sync only); stride addressing
strictly by physical tensors; `-fmad=false` on all math-critical kernels;
device-driven decode with bulk token drain (Qwen3.5 Round 26 etalon).

New files:
- `libs/lsxcommon/src/qwen_moe_exp_model.h` (constants + class decl)

`class Qwen38FlashNextModel final : public lsxcommon::ModelBase`,
`static constexpr const char* kType = "qwen3.8-flash-next";` registered in
`EnsureModelRegistry()` (`model_registry.cpp`). Implements
Load/Infer/Unload/Inspect/SelfCheck/Tokenizer.

Infer loop: embed → repeat×4 → 48 layers
(PLE(layer 2) → hc → attn/GDN → hc-scatter → hc → MoE → hc-scatter) → global
mixer → lm_head logits. No MTP application (HF parity). SelfCheck: incremental
1→2-token generation forced to `max(2, max_gen_tokens)`; prompt
"The capital of France is" must yield "Paris" (top-1); publishes `gen_tokens`
+ `final_logits` in InferenceResult.

## Error handling

- Converter: hard error on missing config/shards, unknown tensor prefixes
  outside {language_model, mtp, visual, ple}, geometry mismatch, failed
  integrity checks.
- Loader: hard error on missing layer/expert/PLE files or malformed records
  (no silent fallbacks); LRU slot OOM → actionable message with computed
  budget.
- Runtime: router degenerate cases (NaN logits) fail fast; PLE hash out-of-range
  index is a hard error (never silent wrap).

## Risks / open verification points (resolve during planning)

1. Exact PLE n-gram indexing formula (head offsets × multipliers over
   unigram/bigram/trigram context) — pin against
   `Qwen4ExpTextNGramEmbedding.forward` with a Python parity test before the
   CUDA kernel is written.
2. QSA decode cost at seq=1: indexer recomputes block scores over the full
   key cache each token — measure early; if hot, move pooled-key
   precomputation into the incremental state (block-pooled keys are append-only).
3. LRU hit rate with 16 slots × 281 GiB touched/token — expected cold-start
   storm on prefill; profile before optimizing (slot prefetch on router output
   is the known lever from the Kimi/GLM caches).
4. hc group-RMSNorm + division by hc_count must replicate torch float32
   intermediate casting — verify bit-exactness on the kernel test fixture.
