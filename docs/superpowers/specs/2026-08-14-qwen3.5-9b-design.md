# Qwen3.5-9B Support Design

## Purpose

Add end-to-end Qwen3.5-9B text inference alongside the existing
DeepSeek-V4-Flash and GLM-5.2 paths: a converter (`--qwen`) that emits a
`logestix-qwen` arrow layout with every dense linear weight NVFP4-quantized, a
host-side pinned-weights loader, CUDA inference kernels for both the
GatedDeltaNet linear-attention and the gated full-attention blocks, an `IModel`
implementation registered in the model factory (`qwen3.5-9b`), validator
support, and a TDD unit-test suite.

Text-only scope. The vision encoder (`visual.*`) and the MTP module (`mtp.*`)
are not implemented; their tensors are skipped during conversion (HF itself
ignores `mtp.*` at load via `_keys_to_ignore_on_load_unexpected`).

Target platform for this session: Windows (VS 2026, `windows-debug` preset,
RTX 5060 Ti 16GB, CUDA 13.3).

## Reference Architecture

Qwen3.5-9B is a Qwen3-Next hybrid text decoder
(`Qwen3_5ForConditionalGeneration`, `model_type=qwen3_5`). Reference math:
`transformers` `modeling_qwen3_5.py` (fetched 2026-08-14).

Text geometry (from the real `config.json`):

### Layer block types

`Qwen3_5DecoderLayer` (residual, pre-norm):

```
residual = x
x = input_layernorm(x)
if layer_types[i] == linear_attention:  x = linear_attn(x)
else:                                   x = self_attn(x)
x = residual + x
residual = x
x = post_attention_layernorm(x)
x = mlp(x)               # SwiGLU: silu(gate(x)) * up(x) then down
x = residual + x
```

### Full attention (`Qwen3_5Attention`)

- `q_proj` out = `num_heads*head_dim*2` → split into `query_states` and `gate`
  (per-feature output gate).
- `q_norm`, `k_norm` — `Qwen3_5RMSNorm` on head_dim (offset-weight form,
  see below), applied per head **before** rotary.
- Partial RoPE on the first `0.25*head_dim = 64` dims, theta 1e7. For pure text
  all three mRoPE position dims are identical, so the interleaved mRoPE reduces
  to a plain 64-dim RoPE.
- GQA: 16 query heads, 4 KV heads (`repeat_kv` ×4).
- scale = `head_dim^-0.5` = 1/16.
- `attn_output = attn_output * sigmoid(gate)`; then `o_proj`.

### Linear attention (`Qwen3_5GatedDeltaNet`)

- `in_proj_qkv` (4096 → 8192 = k_dim*2+v_dim) → depthwise **causal conv1d**
  kernel=4, groups=8192 (no bias) → split q,k,v.
- `q_dim = k_dim = 16*128 = 2048`, `v_dim = 32*128 = 4096`.
- `z = in_proj_z(x)` (→ 4096), `b = in_proj_b(x)` (→ 32), `a = in_proj_a(x)` (→ 32).
- reshape q,k to `[bs, seq, 16, 128]`, v,z to `[bs, seq, 32, 128]`.
- `beta = sigmoid(b)`.
- `g = -exp(A_log) * softplus(a + dt_bias)` — per v-head decay.
- repeat_interleave q,k by `32/16 = 2`.
- Gated delta rule, recurrent form (matches `torch_recurrent_gated_delta_rule`,
  `use_qk_l2norm_in_kernel=True`, scale `1/sqrt(128)`):

```
for t:
  q,l2 = l2norm(q, 1e-6); q *= 1/sqrt(128)
  k,l2 = l2norm(k, 1e-6)
  S = S * exp(g_t)                        # state [v_head, k_dim, v_dim]
  kv_mem = (S * k_t).sum(k_dim)           # [v_head, v_dim]
  delta = (v_t - kv_mem) * beta_t
  S = S + k_t[..., None] * delta[..., None, :]
  out_t = (S * q_t).sum(k_dim)
```

- `core_attn_out = Qwen3_5RMSNormGated(core_attn_out, z)`:
  `rmsnorm(core) * weight * silu(z)` (plain form, weight[ones]).
- `out_proj` (4096 → 4096).

### RMSNorm — two variants

Two distinct norm forms; do not conflate them:

- `Qwen3_5RMSNorm` (input_layernorm, post_attention_layernorm, q_norm, k_norm,
  final `norm`): weight initialized to **zeros**, forward is the **offset form**
  `out = rmsnorm(x) * (1.0 + w)`.
- `Qwen3_5RMSNormGated` (linear-attn `linear_attn.norm`): weight initialized to
  **ones**, forward is the **plain form** `out = rmsnorm(x) * w * silu(z)`
  (no `1+w`, no offset).

Loader stores weights verbatim; kernels must apply the correct form per
tensor: `(1.0 + weight[i])` for the layer/q/k/final norms, `weight[i]` for the
linear-attn norm.

### MTP (`mtp.*`)

Not part of the inference path (HF ignores it). Converter skips with a log
warning.

## Converter (`qwen_convert.cpp`, `--qwen`)

Mirror `glm::ConvertGlmModel`. Single CPU safetensors scan (simdjson), name
classification:

- **Global** (`pinned/global.arrow`):
  - `model.language_model.embed_tokens.weight` → NVFP4
  - `lm_head.weight` → NVFP4
  - `model.language_model.norm.weight` → raw BF16
- **Layer N** (`pinned/layer_NNN.arrow`, unpadded N):
  - linear_attn: `in_proj_qkv`, `in_proj_z`, `in_proj_b`, `in_proj_a`,
    `out_proj`, `conv1d.weight` → NVFP4; `A_log` (F32), `dt_bias` (F32),
    `norm.weight` (BF16) → raw
  - full_attn: `q_proj`, `k_proj`, `v_proj`, `o_proj` → NVFP4;
    `q_norm.weight`, `k_norm.weight` → raw BF16
  - mlp: `gate_proj`, `up_proj`, `down_proj` → NVFP4
  - `input_layernorm.weight`, `post_attention_layernorm.weight` → raw BF16
- **Skipped**: `mtp.*`, `visual.*`, unknown → log warning.

NVFP4 quantization reuses `gpu::quantize_tensor_gpu` (E2M1 weights + E4M3
per-16 block scales + global scale), the exact path `PackExpertNVFP4` uses, but
applied to every dense linear weight.

### New schema `DenseNvfp4Schema` (`schema.h`/`schema.cpp`)

6 columns, one row per tensor:

| Col | Type |
|---|---|
| name | utf8 |
| shape | list(int64) |
| dtype | utf8 |
| packed | large_binary |
| scales | list(uint8) |
| global_scale | float32 |

`Make()` / `MakeBatch(vector<DenseNvfp4Record>)` / `UnpackBatch`. Raw tensors
keep using `PinnedSchema`.

`layer_types` drives runtime per-layer dispatch.

## Loader (`qwen_inference_load.cpp`)

Host-side, mirrors `glm_inference_load.cpp`. Accepts both
`<model>/logestix/pinned` and `<output_root>/pinned`.

- `QwenTopology` struct + `load_qwen_topology(index_path)` (simdjson).
- `QwenLayerWeights`: per layer — `input_norm`, `post_norm` (FP16);
  linear_attn: `d_qkv`, `d_z`, `d_b`, `d_a`, `d_out` (packed NVFP4 + scales +
  global), `d_conv1d` (FP16), `d_A_log`/`d_dt_bias` (F32), `d_attn_norm`
  (FP16); full_attn: `d_q`, `d_k`, `d_v`, `d_o` (packed), `d_q_norm`,
  `d_k_norm` (FP16); mlp: `d_gate`, `d_up`, `d_down` (packed).
- `QwenPinnedWeights`: `d_embed`, `d_head`, `d_final_norm`, topology,
  `vector<QwenLayerWeights> layers`.
- `LoadQwenPinnedWeights(model_path, QwenPinnedWeights&, stream, layer_filter)`.
- BF16→FP16 host upload (bit-twiddle) for raw tensors; NVFP4 packed/scales/
  global uploaded as raw bytes. F32 (`A_log`, `dt_bias`) uploaded as-is.

## CUDA kernels (`qwen_inference.cu`, OBJECT lib `lsxcommon_qwen_cu`)

New OBJECT lib mirroring `lsxcommon_glm_cu` (`--extended-lambda`, arch
`120-real;121-real`; no `-fmad=false` requirement since tests compare to FP64
CPU references with tolerance, not bit-exact match). Kernels:

- `rms_norm_qwen` — offset-weight form `(1.0+w)`.
- `partial_rope_qwen` — rotate first 64 of 256 dims.
- `qwen_full_attn` — q_proj(2×dim)+split/gate, q/k norm, rope, GQA, scaled
  dot-product softmax causal, output ×sigmoid(gate), o_proj.
- `qwen_linear_attn` — conv1d, q/k l2norm, gated delta recurrence (per-v-head
  `S[k,v]` state, recurrent, no chunking), RMSNormGated, out_proj.
- `qwen_nvfp4_gemm` — fused NVFP4-decode + GEMM (decode E2M1 with E4M3 block
  scales + global scale on the fly, reuse `shared_experts.cu` decode tables).
  FP16 materialization is impossible (18GB > 16GB VRAM), so decode-per-tile is
  required.
- `qwen_mlp` — SwiGLU dense.
- `RunQwenGeneration(ch, st, pw, input_ids, max_gen, gen)` — greedy, mirrors
  `RunGlmGeneration`.

Async pipeline: non-blocking streams/events, no `cudaDeviceSynchronize` in the
hot loop (per AGENTS.md).

## IModel + registry

- `QwenV5Model` (`qwen_v5_model.cpp` + `.h`), registry key `qwen3.5-9b`,
  mirrors `GlmV5Model`. Load() opens tokenizer arrows
  (`load_tokenizer_metadata`; Qwen ships a `tokenizer.json`, ByteLevel BPE —
  already supported by `tokenizer_convert.cpp`). Infer → `RunQwenGeneration`,
  SelfCheck, Inspect, Unload.
- Register in `model_registry.cpp` `EnsureModelRegistry()`.

## Validator (`apps/lsxfabric/src/validator.cpp`)

Extend to handle `logestix-qwen`: validate `DenseNvfp4Schema` packed nibbles
(E2M1), E4M3 scales, global_scale, and raw norm tensor presence. Reuse the
existing E2M1/E4M3 validators.

## TDD Test Suite (`tests/`)

`tests/qwen_test_fixture.h` — synthetic Qwen model builder (mirror
`glm_test_fixture.h`): tiny geometry (e.g. hidden 64, 4 layers, mixed
`layer_types`, small linear dims, vocab 64), built with `WriteSafetensors`.
CPU FP64 reference implementations of every op for tolerance checks.

Test executables (each an `add_executable` + `add_test` block in
`tests/CMakeLists.txt`, WIN32 arrow.dll POST_BUILD copy):

1. `test_qwen_convert` — classifier, `logestix-qwen` index topology,
   NVFP4 round-trip, MTP/vision skip.
2. `test_qwen_loader` — BF16→FP16 norms, topology sizing, packed NVFP4 upload,
   layer_types dispatch.
3. `test_qwen_norm` — RMSNorm offset form vs CPU.
4. `test_qwen_rotary` — partial rope vs CPU.
5. `test_qwen_mlp` — SwiGLU vs CPU.
6. `test_qwen_full_attn` — gated full attention vs CPU.
7. `test_qwen_linear_attn` — GatedDeltaNet forward vs CPU (FP64 ref).
8. `test_qwen_nvfp4_conv` — converter → NVFP4 dequant GEMM round-trip.
9. `test_qwen_model` — factory + IModel + generation (synthetic model).

## Out of Scope

- Vision encoder (`visual.*`), mRoPE interleaving (plain 64-dim rope only).
- MTP inference.
- Speculative decoding / batched multi-token generation.
- Chunked (parallel) linear-attention forward; recurrent only.
