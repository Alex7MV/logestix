## 3. Classification (Stage 0.1)

**New family `ling`**, registry `kType = "ling"`, output format tag
`logestix-ling-nvfp4`. Reasons it is not a sibling:

- KDA has direct `f_proj`/`g_proj` (GLM-5.3 has `f_a/f_b` + `g_a/g_b`) and no
  hyper-connections.
- Full-attention layers are gated MLA (`attention.dense`, `attention.g_proj`);
  GLM-5.3 uses a DSA indexer.
- Router is group-limited (`n_group 8 / topk_group 4`) with `expert_bias`;
  GLM-5.3 is a plain top-8 noaux_tc.
- Geometry 72+1 / 512 experts / vocab 157 184.

## 4. Semantics verified before coding (Stage 0.6)

- **KDA** (from the vendor `modeling_bailing_moe_v3.py` + FLA `fused_recurrent_kda`):
  `q,k ← l2norm(x, eps=1e-6)`, `q *= 1/sqrt(128)`; conv is depthwise causal
  `silu(conv(window + cur))` before the norm; `g = f_proj(x) + dt_bias`; safe gate
  `gk = -5 · sigmoid(exp(A_log) · g)`; `h ← h · exp(gk)`;
  `v ← β·(v − hᵀk)`, `β = sigmoid(b_proj(x))`; `h ← h + k vᵀ`; `o = hᵀq`;
  output is `RMSNorm_gated(o, sigmoid(g_proj(x)))` per head then `o_proj`.
  Identical to the repo's verified GLM-5.3 KDA math, projections aside.
- **MLA**: `q = q_b(rmsnorm(q_a(x)))` split `[nope 128 | rope 64]`;
  `c = kv_a(x)` split `[kv_lora 512 | rope 64]`;
  `k_nope,v = kv_b(rmsnorm(c[512]))` split per head; the rope 64 is a single
  head-shaped vector expanded to all 64 heads. RoPE is pairwise/interleaved on
  the 64 rope dims (`apply_rotary_pos_emb_interleave` == NeoX pairing with
  `freqs` duplicated). Softmax scale `1/sqrt(192)`, no YaRN/mscale.
  `out *= sigmoid(g_proj(x))` per head, then `dense`.
- **MoE**: shared expert is an UNGATED SwiGLU MLP added to the routed sum.
  `expert_swiglu_limit_list` is unused by the reference implementation and is
  ignored.
- **MTP** is never applied (stored-not-applied; counted as `deferred.mtp`).

## 6. On-disk format (`<output>/logestix`)

- `pinned/global.arrow`: `model.word_embeddings.weight` (BF16), `lm_head.weight`
  (BF16), `model.norm.weight` (BF16).
- `pinned/layer_NNN_nvfp4.arrow`: every FP8 linear of the dense side:
  KDA `q/k/v/o/f/g`, MLA `q_a/q_b/kv_a/kv_b/dense`, dense-MLP
  `gate/up/down` for layers 0–3.
- `pinned/layer_NNN.arrow` (raw, high precision): `input_layernorm`,
  `post_attention_layernorm`, KDA `q/k/v_conv1d` (BF16), `A_log`/`dt_bias`
  (F32), `b_proj` (BF16), `o_norm` (BF16), MLA `q_a_layernorm`/`kv_a_layernorm`
  (BF16), MLA `g_proj` (BF16).
- `router/layer_NNN.arrow`: `mlp.gate.weight` (BF16), `mlp.gate.expert_bias`
  (F32).
- `shared/layer_NNN_nvfp4.arrow`: `mlp.shared_experts.{gate,up,down}_proj`.
- `experts/layer_NNN/exp_EEE.arrow`: `w1 = gate`, `w2 = down`, `w3 = up`
  (neutral `ExpertSchema`).
- `tokenizer/`: `BuildTokenizerArrowFiles` with `pretokenizer = 3`
  (`tokenizer_kind 5`), `bos_id = -1`, eos 156895, pad 156892.
- `model.index.json`: `format`, `model`, `model_type`, `num_layers`,
  `mla_layers`, `kda_layers`, `moe_layers`, `dense_layers`, geometry,
  rope/eps, eos/pad, `vram` block, `deferred: {mtp: N}`, `total_experts`.

## 7. Runtime

Dense side resident (≈ 10.2 GiB NVFP4 + FP16 edges). Routed experts are an mmap
`ExpertStore` (255 GiB tree, no pinning by default), device slot LRU sized from
free VRAM (`LSX_LING_EXPERT_CACHE_SLOTS` override, `LSX_LING_MAX_OPEN` for the
host window, default 4096). Session state:

- MLA KV through `KvCacheGeometry` (pos-major, K `[64][192]`, V `[64][128]`,
  9 layers, ~32 KiB/token).
- KDA: per-layer `[64,128,128]` FP32 recurrent state + `[3, 3*8192]` FP16 conv
  history.
- One stream, token-by-token prefill/decode, `GenerationStream` emit per token,
  abort between steps, residency lock around the decode, governor lease.

Measured throughput 2.77 t/s (perf) / 2.41 t/s (r3) at 2048 tokens
(`tests/perf/perf_baselines.json`).

## 9. Gates and declared debt

- SelfCheck: real weights, Paris ×3 bit-exact.
- Tokenizer parity: real oracle (HF tokenizer on the local machine).
- FSI / CODE / DET: **declared debt**. The source oracle (560 B BF16/FP8 with
  FLA Triton KDA) cannot run on one RTX 5090 and fla has no CPU kernel; no
  golden can be captured from the source. The targets and `kGoldenDebt` rows
  are added so the absence is explicit (Mistral precedent), not a silent SKIP.
- Perf: seeded through `test_perf_baseline` only.

## 10. Risks

- **Expert streaming cost** dominates; the 2048-token protocol is
  disk-bandwidth-bound. The expert store must stay zero-copy (`ExpertStore`,
  never an owning map).
- **KDA/MLA parity** relies on the vendor implementation as the semantic
  reference; each numeric contract gets a host-reference test.
- **FP8 partial tiles** (`kv_a_proj_with_mqa [576,4096]`, scale `[5,32]`) must
  clamp the last tile (the gigachat-style dequant, not the GLM one).
- **2.4 GiB embed/head** in FP16 is required for logit parity.
