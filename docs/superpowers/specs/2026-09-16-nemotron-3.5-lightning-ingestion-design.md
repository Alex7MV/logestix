# NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16 — Ingestion Design

Date: 2026-09-16
Status: approved design, pending implementation plan
Branch: `feat/nemotron-3.5-lightning-ingest`

## Overview

Ingest `NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16` (`NemotronHForCausalLM`,
`model_type=nemotron_h`) into the logestix monorepo following the 8-stage Model
Ingestion Protocol. This is a **new model family** (`nemotron`), not a variant:
the checkpoint is a **hybrid Mamba-2 + MoE + attention** network and the repo
has no selective state-space (SSM) support today. Only model-neutral
infrastructure is reused (`model_base`, `model_runtime`, `expert_store`,
`lsx_inference_nvfp4`, `lsx_gemv`, `tokenizer`, `schema`, `path_registry`,
`gpu_perf`, `sampling`, `resource_governor`).

Source checkpoint (read-only):
`/mnt/llm_models/models/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16`
(14 safetensors shards, BF16, 6513 tensors, 31.58B params, 65.84 GB).
Reference math pinned from `transformers` 5.15.1
`models/nemotron_h/modeling_nemotron_h.py` (the checkpoint declares
`transformers_version=4.57.6`; the architecture is unchanged) and
`models/zamba2/modeling_zamba2.py::Zamba2RMSNormGated`.

Milestone 1 scope (operator decision): the **text backbone end-to-end** —
converter → load → forward for Mamba-2 / MoE / full-attention / final head,
targeting a working `SelfCheck` (`"The capital of France is"` → `"Paris"`).
Deferred and explicitly recorded: the **MTP speculative head** (`mtp.*`).

## Autonomy invariant

- `nemotron_moe_*` must not `#include` any other family's loader/inference
  headers; the geometry is a fresh compile-time frozen block in
  `nemotron_moe_constants.h` under `lsxcommon::nemotron_moe::frozen`.
- Only model-neutral infrastructure and the neutral NVFP4 layer are consumed.
- `test_model_independence_guard.cpp` gets the new passport row, the owner
  marker for `nemotron_moe_constants.h`, and `nemotron_moe_model.cpp` in the
  per-`Infer` `LsxFastMathScope` consumer list; the naming/suite guards get the
  `nemotron` family token — all in the same commit that lands the model.

## Layer plan

`layers_block_type` (legacy tags remapped by the reference:
`mamba→linear_attention`, `attention→full_attention`) is frozen verbatim:

```
0..4   : mamba, moe, mamba, moe, mamba
5      : attention
6..11  : moe, mamba, moe, mamba, moe, mamba
12     : attention
13..18 : moe, mamba, moe, mamba, moe, mamba
19     : attention
20..25 : moe, mamba, moe, mamba, moe, mamba
26     : attention
27..32 : moe, mamba, moe, mamba, moe, mamba
33     : attention
34..41 : moe, mamba, moe, mamba, moe, mamba, moe, mamba
42     : attention
43..51 : moe, mamba, moe, mamba, moe, mamba, moe, mamba, moe
```

Counts: 23 mamba + 23 moe + 6 attention = 52.

Every layer is pre-normalized only:
`x = residual + Mixer(RMSNorm(x))`, with `RMSNorm` weights BF16 and no
attention-bias / mlp-bias. `rescale_prenorm_residual` is a weight-init detail
baked into the checkpoint — it has **no forward effect** and is not implemented.

Output directory follows the vault convention `<model>/logestix/`. The index
(`logestix/model.index.json`) carries:

### Globals (`pinned/global.arrow`)
- `embed.weight` BF16 [131072, 2688]
- `head.weight`  BF16 [131072, 2688] (untied — a real tensor)
- `norm.weight`  BF16 [2688]

### Mamba layer (`pinned/layer_N.arrow`)
- `norm.weight` BF16 [2688]
- `mixer.in_proj.nvfp4`  NVFP4 [10304, 2688] (+ per-16 E4M3 scales + `global_scale`)
- `mixer.out_proj.nvfp4` NVFP4 [2688, 4096]
- `mixer.conv1d.weight` BF16 [6144, 4]; `mixer.conv1d.bias` BF16 [6144]
- `mixer.A_log` F32 [64]; `mixer.D` F32/BF16 [64]; `mixer.dt_bias` F32/BF16 [64]
- `mixer.norm.weight` BF16 [4096] (gated RMSNorm weight)

### Attention layer
- `norm.weight` BF16 [2688]
- `mixer.q_proj.nvfp4` NVFP4 [4096, 2688]
- `mixer.k_proj.nvfp4` / `mixer.v_proj.nvfp4` NVFP4 [256, 2688]
- `mixer.o_proj.nvfp4` NVFP4 [2688, 4096]

### MoE layer
- `norm.weight` BF16 [2688]
- `mixer.gate.weight` BF16 [128, 2688] (kept high precision: sigmoid router,
  consumed at F32)
- `mixer.gate.e_score_correction_bias` F32 [128]
- `mixer.shared_experts.up_proj.nvfp4` NVFP4 [3712, 2688];
  `mixer.shared_experts.down_proj.nvfp4` NVFP4 [2688, 3712]
- routed experts `experts/layer_N/exp_E.arrow`: `up_proj.nvfp4` [1856, 2688],
  `down_proj.nvfp4` [2688, 1856] (per-expert NVFP4, repo layout)

Norms, biases, `A_log`, `D`, `dt_bias`, `conv1d`, `e_score_correction_bias`
are never quantized (MODEL INGEST step 2). `in_proj`/`out_proj`/`conv1d` follow
the checkpoint's bias flags (all false except `conv1d.bias`).

## Pinned reference formulas

### RMSNorm (`NemotronHRMSNorm`)
```
x = x.float(); var = x.square().mean(-1, keepdim=True)
x = x * rsqrt(var + 1e-5); return (weight * x).to(bf16)
```

### Mamba-2 mixer (`NemotronHMamba2Mixer.forward`)
```
A        = -exp(A_log.float())                       # [64]
proj     = in_proj(x)                                # [10304]
gate, xBC, dt = split(proj, [4096, 6144, 64])
# 1. depthwise causal conv (groups=6144, kernel=4, pad=3) + silu
xBC      = silu(conv1d(xBC))                         # conv carries bias
# 2. split state SSM operands
xs, B, C = split(xBC, [4096, 8*128, 8*128])
xs       = xs.view(64, 64); B = B.view(8,128); C = C.view(8,128)
# 3. selective state update (decode / recurrent form)
dt       = softplus(dt + dt_bias)                    # clamp min 0.001
dA       = exp(dt * A)                               # [head, head_dim, state]
dB       = dt * B                                    # B broadcast over heads
state    = state * dA + dB * xs[..., None]
out      = (state · C) + xs * D                      # [64, 64]
# 4. gated RMSNorm (silu gate) over group=512, then out_proj
out      = gated_rmsnorm(out.flatten(4096), gate)
y        = out_proj(out)
```
The **sequential recurrent form** is used for both prefill and decode
(mathematically identical to the reference chunk scan; only FP accumulation
order differs). `chunk_size=128` is therefore not needed in milestone 1.
Rounding note: unlike `mamba2_chunk_scan`, the torch decode fallback does not
clamp `dt` (only `softplus`); the CUDA `selective_state_update` kernel clamps to
`[time_step_min, +inf)`. Milestone 1 clamps to `kDtMin` for both paths and
documents the deviation.

### Gated RMSNorm (`Zamba2RMSNormGated`)
```
h = h.float() * silu(gate.float())            # gate = mixer z
h = h.view(-1, 8, 512)
var = h.square().mean(-1, keepdim=True)
h = h.view(-1,4096) * rsqrt(var + 1e-5)
return weight * h.to(bf16)
```

### Full attention (`NemotronHAttention`)
```
q = q_proj(x).view(32,128); k = k_proj(x).view(2,128); v = v_proj(x).view(2,128)
(q,k) = rope_full(q,k, pos)                  # all 128 dims, theta 10000
attn  = softmax(q·kᵀ * 128^-0.5) (causal, F32); GQA 16:1
o     = attn·v → o_proj
```

### Router (`NemotronHTopkRouter`)
```
logits = x.float() @ gate.weight.float()     # F32
scores = sigmoid(logits)
scores_for_choice = scores + e_score_correction_bias
# n_group = 1 -> group stage is the identity over all 128 experts
idx = topk(scores_for_choice, 6)             # bias selects only, never scales
w   = scores.gather(idx)
w  /= w.sum(-1, keepdim=True) + 1e-20        # norm_topk_prob
w  *= 2.5                                    # routed_scaling_factor
```

### MoE (`NemotronHMoE` / `NemotronHExperts`)
```
routed = Σ_{e in topk} w_e * down_e(relu2(up_e(x)))
shared = shared_down(relu2(shared_up(x)))    # ungated, all tokens
out    = routed + shared
```
Experts have no gate projection (`up`/`down` only), unlike DeepSeek/Qwen.

## Inference data flow and state

`embed(BF16) → for layer in 0..51: x = residual + Mixer(RMSNorm(x)) → norm_f → head(F32 logits) → sample`.

Per-session device state:
- **KV cache** for the 6 attention layers only (32 Q / 2 KV heads, head_dim 128).
- **Mamba-2 recurrent state** for the 23 mamba layers:
  `[64, 64, 128]` F32 per layer (~2 MiB) + **conv state** `[6144, 3]` F16.
  Total ≈ 48 MiB F32 + 1.7 MiB F16 — negligible vs the weight set.

The layer walk is heterogeneous (mamba / moe / attention), reusing the same
scheduling pattern as the Qwen3.8-Flash-Next GDN hybrid. Single CUDA stream, no
per-token `cudaDeviceSynchronize`; reductions use the shared-memory sandbox
(thread-0 + barriers).

## Testing strategy (TDD)

Strict red→green per stage; every new target gets its ctest label in the same
commit, and the selfcheck target gets `SKIP_RETURN_CODE 4`.

1. **fast/host** — constants `static_assert`s; registry `kType` resolution and
   frozen-geometry rejection; `layers_block_type` decoding; router/gated-norm
   reference math in `nemotron_moe_device_math.h`.
2. **convert** (label `convert`, bounded TIMEOUT ≤120 s) — synthetic E2E on
   `test_synth_checkpoint.h`: globals + one layer of each block type + all 128
   routed experts for one MoE layer; assert the `logestix-nemotron-nvfp4` index,
   NVFP4 scale geometry, untouched high-precision tensors, and the counted MTP
   cut. No real-model conversion in tests.
3. **load** — synthetic converted fixture only; strictness on missing/corrupt
   tensors, format-tag gate, frozen-geometry gate, expert LRU bookkeeping.
4. **kernels** — device vs host reference parity, bit-exact target with
   `-fmad=false`: depthwise causal conv + silu, selective state update, gated
   RMSNorm (group 512), relu² expert MLP, sigmoid router top-6 with
   `e_score_correction_bias`, full RoPE attention.
5. **selfcheck** — incremental 1→2-token `"Paris"` over ≥3 cycles
   (`LSX_TEST_NEMOTRON_SELFCHECK_CYCLES`), bit-exact `final_logits`, real model
   via env (`LSX_TEST_NEMOTRON_ROOT`), `SKIP()` when absent.

Perf: `tests/perf/perf_baselines.json` entry + `test_perf_baseline_nemotron`
target (label `perf`), measured after correctness.

## Error handling and strictness

- Load rejects a non-`logestix-nemotron-nvfp4` index, a geometry mismatch vs
  the frozen passport, and any missing / mis-shaped / corrupt tensor with a
  diagnostic naming the tensor.
- Conversion is strict: `mtp.*` is the only cut, with a counted record; any
  other unknown tensor is an error — never silently ignored.
- `SelfCheck` returns `selfcheck_passed=false` with the decoded token on
  failure; no partial-success state.

## Risks / decision points

- **Primary:** Mamba-2 is net-new (no SSM precedent in the repo). The
  selective-state-update, depthwise causal conv and gated RMSNorm kernels are
  the risky surface; kernel tests pin each against the host reference before
  the layer pipeline is wired.
- Recurrent-state plumbing across the heterogeneous layer walk (23 stateful
  layers) must not break the single-stream / no-sync invariant.
- The reference decode fallback does not clamp `dt`; normal-path clamp choice is
  documented and pinned by a kernel test.
- MTP is cut: the backbone selfcheck does not depend on it (HF ignores `mtp.*`
  on load), so this is not expected to perturb `"Paris"`.

## Out of scope (follow-ups)

MTP speculative decoding; chunked-scan prefill optimization; performance tuning
(bit-exact correctness first); any multimodal surface (none in this checkpoint).
