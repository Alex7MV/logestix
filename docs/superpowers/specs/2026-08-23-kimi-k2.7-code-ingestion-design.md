# Kimi-K2.7-Code — Model Ingestion Design

Date: 2026-08-23
Status: approved (design), pending implementation plan
Protocol: MODEL INGEST INVARIANT (8 stages, AGENTS.md)
Approach: A — dedicated `kimi_*` stack modeled on GLM-5.2

## Goal

Full-cycle integration of MoonshotAI Kimi-K2.7-Code into the logestix inference
stack: lsxforge conversion of the vault checkpoint, NVFP4 runtime format,
factory registration under `kimi-k2.7-code`, deterministic SelfCheck
("The capital of France is" → "Paris"), full TDD test suite green on the RTX 5090
dev box.

## Source checkpoint facts (verified on disk)

- Vault path: `/mnt/llm_models/models/Kimi-K2.7-Code` (via `path_registry`).
- Multimodal shell `KimiK25ForConditionalGeneration`; text backbone is
  DeepseekV3-style (`model_type: kimi_k2`). Vision tower / mm_projector are
  stripped fat.
- 61 layers, hidden 7168, 64 heads; MLA: kv_lora_rank 512, q_lora_rank 1536,
  qk_nope 128, qk_rope 64, v_head_dim 128; yarn rope scaling factor 64,
  original_max_position_embeddings 4096, rope_theta 50000.
- MoE: 384 routed + 1 shared expert, top-8, sigmoid scoring, noaux_tc
  (n_group=1), norm_topk_prob, routed_scaling_factor 2.827,
  `e_score_correction_bias` per layer; moe_intermediate_size 2048;
  first_k_dense_replace=1 (layer 0 dense MLP, intermediate 18432).
- Vocab 163840; bos `[BOS]`=163584, eos `[EOS]`=163586, pad=163839 (from config).
- Weight dtypes: experts are compressed-tensors INT4 group-32 symmetric —
  `weight_packed` int32 [out, in/8] + BF16 `weight_scale` [out, in/32];
  attention projections, shared experts, dense MLP, lm_head, norms are BF16;
  router gate bias F32.
- Tokenizer: tiktoken ranks file (`tiktoken.model`, lines `base64 rank`), NOT
  HF merges JSON.

## Stage 1–2: Topology & conversion (`lsxforge`)

New files:

- `libs/lsxcommon/src/kimi_convert.cpp`
- `libs/lsxcommon/include/lsxcommon/kimi_convert.h` — entry point
  `ConvertKimiModel` (+ Topology struct), analogous to GLM/Qwen converters.
- CLI flag `--kimi` in `apps/lsxforge`.

Parsing:

- `config.json`: read only `text_config`; `vision_config` ignored.
- `model.safetensors.index.json`: shard mapping; strip `language_model.model.`
  prefix; skip `vision_tower.*`, `mm_projector.*`.
- Clean structural manifest saved via `lsxcommon::lsx_model_metadata(
  "kimi-k2.7-code/...")` — no hardcoded paths outside `path_registry`.
- `model.index.json` builder follows the `qwen_convert.cpp` streaming-builder
  pattern.

Compile-time geometry lock (new-model requirement): hidden=7168, layers=61,
heads=64, kv_lora_rank=512, q_lora_rank=1536, qk_nope_head_dim=128,
qk_rope_head_dim=64, v_head_dim=128, n_routed_experts=384, num_experts_per_tok=8,
n_shared_experts=1, moe_intermediate_size=2048, first_k_dense_replace=1,
vocab_size=163840. Enforced by `static_assert` in the model header; config
values are cross-checked at load and mismatch = hard error.

Quantization pipeline (streaming per-tensor GPU, no full intermediate buffer):

- BF16 tensors (attn projections, shared expert, dense layer 0, lm_head) →
  existing `safetensors_gpu.cu` kernels → NVFP4.
- INT4 experts → new CUDA unpack kernel (`weight_packed` int32 → 8 E2M1-range
  nibbles) → dequant multiply by BF16 `weight_scale` (group 32 along input
  dim) → BF16 → same NVFP4 path.
- Norms and biases stay FP16/BF16 — never quantized (precision invariant).

Runtime format identical to GLM/Qwen: E2M1 nibble-packed weights + per-block
E4M3 scales (uint8[]) + float32 global_scale.

Disk feasibility: NVFP4 output ≈ 500–550 GB; vault volume has ~720 GB free.

## Stage 3: Factory registration

- `KimiK27CodeModel` (final, `lsxcommon::IModel`), `kType = "kimi-k2.7-code"`,
  files `libs/lsxcommon/src/kimi_v5_model.{h,cpp}`.
- Registered in `libs/lsxcommon/src/model_registry.cpp`.
- Implements Load / Infer / Unload / Inspect / SelfCheck / Tokenizer.
- Infer loop: dense layer 0 → MLA attention + MoE layers 1–60 (expert
  streaming from pinned host arenas) → final norm + lm_head.

## Stage 4: Token bridge

Extend `libs/lsxcommon/src/tokenizer_convert.cpp` with a tiktoken parser:

- Parse `tiktoken.model` lines (`base64 rank`), base64-decode → vocab.
- Reconstruct merges from ranks: each token's first split into a byte-pair
  yields a merge record ordered by rank priority (equivalent BPE semantics).
- Special tokens from `tokenizer_config.json` special list.
- bos/eos/pad read from model config (163584/163586/163839) — no hardcoded IDs
  in kernels; `bos_id >= 0` semantics per existing tokenizer.cpp.

Stage 7 (passport): `passport.bin` regenerated via `lsxnetwork::BuildPassport`;
`LsxTokenTranslator` as `alignas(64)` member of IoWorker; `Load()` strictly
after `CpuAffinity::PinToCores0To3` and before `set_value()`.

## Stage 5–6: CUDA kernels & invariants

New OBJECT library `lsxcommon_kimi_cu` (linked PUBLIC into `lsxcommon`),
compiled with `-fmad=false` for bit-exact math, mirroring `lsxcommon_glm_cu`:

- `libs/lsxcommon/src/kimi_inference.cu`:
  - MLA attention: q LoRA down/up (1536), kv compression to latent 512 +
    rope branch 64, latent KV cache, decode softmax with yarn scaling
    (factor 64, mscale 1.0);
  - Router: sigmoid + e_score_correction_bias, noaux_tc top-8 (n_group=1),
    norm_topk_prob, ×2.827 routed scaling;
  - Expert FFN: NVFP4 decode + SwiGLU, geometry 7168↔2048×2, streamed from
    pinned arenas (384 experts do not fit 32 GB VRAM).
- `libs/lsxcommon/src/kimi_device_math.h`: bit-exact glibc replication for the
  functions Kimi needs.
- Loader fast path: `libs/lsxcommon/src/kimi_inference_load.{h,cpp}` —
  `LoadKimiPinnedWeights`: zero-copy Arrow IPC view, pinned staging ring,
  per-layer device arenas, GPU BF16→FP16 in-place; strict errors on missing
  layer files / broken tensors.

Invariants (no deviations):

- Single end-to-end `cudaStream_t` for prefill+decode; no
  `cudaDeviceSynchronize` inside the token loop (final sync only).
- Stride arithmetic for Q/K/V strictly from physical tensor geometry.
- Shared-memory RMW only by thread 0 behind `__syncthreads()` barriers;
  post-barrier reads are read-only.
- CCCL/cub reductions; tile programming for Blackwell (CC 12.x); ≤48 warps/SM.
- abseil containers host-only; no `absl/container/*` in any header reachable
  from `.cu`/`.cuh` TUs.

Validation: extend `apps/lsxfabric/src/validator.cpp` to cover the assembled
Kimi model (NVFP4/E4M3/global-scale checks).

## Stage 8: TDD test plan

Red-green per unit: failing test first, then implementation. Suite
`tests/test_kimi_*` (full set, GLM-analogous); real-weight tests SKIP without
vault weights:

| Test | Verifies |
|---|---|
| `test_kimi_convert.cpp` | config/index parsing, prefix stripping, manifest in vault |
| `test_kimi_int4_dequant.cu` | INT4 unpack + scale vs CPU reference (synthetic tensors) |
| `test_kimi_tokenizer.cpp` | tiktoken ranks → vocab+merges, encode/decode round-trip, special tokens, bos/eos/pad |
| `test_kimi_loader.cpp` | Arrow IPC → pinned, strict errors on broken inputs |
| `test_kimi_moe_router.cpp` | sigmoid + bias + noaux_tc top-8 + scaling, bit-exact |
| `test_kimi_attention.cu` | MLA projections, yarn rope, latent KV cache, stride invariants |
| `test_kimi_experts.cu` | NVFP4 decode + SwiGLU 7168↔2048 |
| `test_kimi_model.cpp`, `_inference.cpp`, `_full_compute.cpp` | lifecycle, Load/Infer/Unload/Inspect |
| `test_kimi_selfcheck.cpp` | incremental 1→2-token SelfCheck, "The capital of France is" → "Paris", 3 stress cycles with bit-exact `final_logits`, override `LSX_TEST_KIMI_SELFCHECK_CYCLES`, exit 0 |

Tests registered in `tests/CMakeLists.txt`; run isolated via `ctest -R kimi`.

## Out of scope

- Vision tower / multimodal inference (stripped at conversion).
- Serving/chat-template framing beyond what existing prompt-framing tests
  require.
- Any pre-Blackwell architecture targets.
