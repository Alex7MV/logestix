**Goal:** Ingest the hybrid Mamba-2 + MoE + attention checkpoint `NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16` into logestix end-to-end, targeting `SelfCheck("The capital of France is") -> "Paris"`.

**Architecture:** New `nemotron` family (`nemotron_moe_*`) per the 8-stage Model Ingestion Protocol. Converter → NVFP4 (dense linears only) → frozen-geometry model class → Mamba-2 / full-attention / MoE device kernels → tokenizer bridge → SelfCheck + guards. **Tech Stack:** C++20/C23, CUDA CC 12.0/12.1 (Blackwell), CMake 3.25+ presets, Arrow 25.0.1, spdlog, abseil, CCCL 3.4.2, Catch2 v3.16.0, NVFP4 via the neutral `lsx_inference_nvfp4`/`lsx_gemv` layer.

**Spec:** `docs/superpowers/specs/2026-09-16-nemotron-3.5-lightning-ingestion-design.md`

## Global Constraints

- Branch: `feat/nemotron-3.5-lightning-ingest` (already created).
- Target arch: CC 12.0 / 12.1 only; Hopper/Ada/Ampere forbidden. Max 48 warps/SM.
- CUDA: one stream, no per-token `cudaDeviceSynchronize`; shared-mem sandbox (thread-0 RMW behind `__syncthreads()`); no `atomicAdd` feeding `final_logits`.
- NVFP4 only through the model-neutral `lsx_inference_nvfp4` layer; no family-owned NVFP4 dispatcher.
- Norms, biases, `A_log`, `D`, `dt_bias`, `conv1d`, `e_score_correction_bias`, router gate stay high precision — never quantized.
- Never read geometry from `config.json` at runtime for the backbone: compile-time constants + `static_assert`, and `Load` fails on a passport mismatch.
- No `std::cout`/`printf`; log via spdlog. Host-only C++ prefers `absl::` containers (`flat_hash_map`, `btree_map`); `.cu`/`.cuh` stay `std::`.
- No abseil containers in any header reachable from `.cu`/`.cuh`.
- Every new test gets its ctest label in the same commit; selfcheck targets get `SKIP_RETURN_CODE 4`.
- Loader-stage tests use synthetic fixtures only; never open the vault.
- Commits only when the operator asks; message prefixes `build:`/`feat:`/`fix:`/`refactor:`/`test:`/`docs:`.

Create `libs/lsxcommon/src/nemotron_moe_device_math.h` with the five functions above, implementing the spec formulas. Key bodies:

```cpp
inline float Relu2(float x) { const float r = x > 0.0f ? x : 0.0f; return r * r; }

inline float Silu(float x) { return x / (1.0f + std::exp(-x)); }

inline void GatedRmsNorm(const float *x, const float *gate, const float *weight,
                         int n, int group_size, float eps, float *out)
{
    const int groups = n / group_size;
    for (int g = 0; g < groups; ++g) {
        const int base = g * group_size;
        double ss = 0.0;
        for (int i = 0; i < group_size; ++i) {
            const float h = x[base + i] * Silu(gate[base + i]);
            ss += double(h) * double(h);
        }
        const float inv = 1.0f / std::sqrt(float(ss / group_size) + eps);
        for (int i = 0; i < group_size; ++i) {
            const float h = x[base + i] * Silu(gate[base + i]);
            out[base + i] = weight[base + i] * h * inv;
        }
    }
}
```

`SelectiveStateUpdate`: `dt_i = softplus(dt[h] + dt_bias[h])` (clamp min `kDtMin`), `A[h] = -exp(A_log[h])`, for each head `h`, group `g = h / (heads/groups)`: `dA = exp(dt_i * A[h])`, for each `d in head_dim`, `s in state_size`: `st[d][s] = st_in[d][s]*dA + dt_i*B[g][s]*xs[h][d]`; `out[h][d] = Σ_s st[d][s]*C[g][s] + xs[h][d]*D[h]`.

`RouterTopK`: `s = sigmoid(logits[e])`, `choice = s + bias[e]`, select top-k indices by `choice`; `w = s[idx]`; `w /= sum(w) + 1e-20`; `w *= scale`.

`ExpertMlpRelu2`: `out[j] = Σ_i down[j][i] * Relu2(Σ_k up[i][k]*x[k])`.
