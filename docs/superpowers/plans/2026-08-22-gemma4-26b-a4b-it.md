# Gemma-4-26B-A4B-it Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate `gemma-4-26B-A4B-it` end-to-end: lsxforge converter (GLM-style layout), GLM-style loader with mmap expert LRU, CUDA inference kernels, factory registration, TDD suite with real-model Paris selfcheck under the Gemma chat template.

**Architecture:** New isolated `lsxcommon::gemma` namespace mirroring the Qwen pipeline file layout. Dense weights stay raw BF16→FP16 (GLM-style arena uploads); routed experts only are NVFP4-packed, stored one-file-per-expert and loaded on demand through `expert_store::ExpertStore`. One end-to-end `cudaStream_t` per generation.

**Tech Stack:** C++20, CUDA 13.3 (CC `120-real;121-real`), Arrow 25 IPC, Catch2 v3, spdlog, abseil (host-only), simdjson.

**Spec:** `docs/superpowers/specs/2026-08-22-gemma4-26b-a4b-it-design.md`

// libs/lsxcommon/src/gemma4_convert.cpp  (this task adds only the classifier)
#include "lsxcommon/gemma4_convert.h"

#include <optional>
#include <regex>

#include <absl/container/flat_hash_map.h>
#include <absl/strings/numbers.h>

namespace lsxcommon {
namespace gemma {

namespace {

std::optional<ParsedTensor> match_layer(const std::string &name,
                                        const std::regex &re, TensorKind kind)
{
    std::smatch m;
    if (!std::regex_match(name, m, re)) return std::nullopt;
    ParsedTensor p;
    p.kind = kind;
    absl::SimpleAtoi(m[1].str(), &p.layer);
    return p;
}

std::regex &re_linear(const std::string &suffix)
{
    static absl::flat_hash_map<std::string, std::regex> cache;
    const std::string pat =
        R"((?:model\.)?language_model\.layers\.(\d+)\.)" + suffix;
    auto it = cache.find(suffix);
    if (it == cache.end())
        it = cache.emplace(suffix, std::regex(pat)).first;
    return it->second;
}

} // namespace

ParsedTensor classify_gemma_tensor(const std::string &name)
{
    using K = TensorKind;

    if (name.rfind("model.vision_tower.", 0) == 0 ||
        name.rfind("model.embed_vision.", 0) == 0 ||
        name.rfind("vision_tower.", 0) == 0)
        return {K::Visual, -1};
    if (name == "model.audio_token_id" || name.find("audio") != std::string::npos)
        return {K::Visual, -1};

    if (name == "model.language_model.embed_tokens.weight") return {K::Embed, -1};
    if (name == "model.language_model.norm.weight") return {K::FinalNorm, -1};

    auto P = [&](K kind, const char *suffix) -> std::optional<ParsedTensor> {
        return match_layer(name, re_linear(suffix), kind);
    };

    if (auto p = P(K::ExpertsGateUp,       R"(experts\.gate_up_proj$)"))                 return *p;
    if (auto p = P(K::ExpertsDown,         R"(experts\.down_proj$)"))                    return *p;
    if (auto p = P(K::RouterProj,          R"(router\.proj\.weight$)"))                  return *p;
    if (auto p = P(K::RouterScale,         R"(router\.scale$)"))                         return *p;
    if (auto p = P(K::RouterPerExpertScale,R"(router\.per_expert_scale$)"))              return *p;
    if (auto p = P(K::LayerScalar,         R"(layer_scalar$)"))                          return *p;
    if (auto p = P(K::PreFFN2,             R"(pre_feedforward_layernorm_2\.weight$)"))   return *p;
    if (auto p = P(K::PostFFN2,            R"(post_feedforward_layernorm_2\.weight$)"))  return *p;
    if (auto p = P(K::PreFFN,              R"(pre_feedforward_layernorm\.weight$)"))     return *p;
    if (auto p = P(K::PostFFN,             R"(post_feedforward_layernorm\.weight$)"))    return *p;
    if (auto p = P(K::AttnQNorm,           R"(self_attn\.q_norm\.weight$)"))             return *p;
    if (auto p = P(K::AttnKNorm,           R"(self_attn\.k_norm\.weight$)"))             return *p;
    if (auto p = P(K::AttnQ,               R"(self_attn\.q_proj\.weight$)"))             return *p;
    if (auto p = P(K::AttnK,               R"(self_attn\.k_proj\.weight$)"))             return *p;
    if (auto p = P(K::AttnV,               R"(self_attn\.v_proj\.weight$)"))             return *p;
    if (auto p = P(K::AttnO,               R"(self_attn\.o_proj\.weight$)"))             return *p;
    if (auto p = P(K::MlpGate,             R"(mlp\.gate_proj\.weight$)"))                return *p;
    if (auto p = P(K::MlpUp,               R"(mlp\.up_proj\.weight$)"))                  return *p;
    if (auto p = P(K::MlpDown,             R"(mlp\.down_proj\.weight$)"))                return *p;
    if (auto p = P(K::InputNorm,           R"(input_layernorm\.weight$)"))               return *p;
    if (auto p = P(K::PostNorm,            R"(post_attention_layernorm\.weight$)"))      return *p;

    return {K::Unknown, -1};
}

bool gemma_tensor_is_nvfp4(TensorKind kind)
{
    return kind == TensorKind::ExpertsGateUp || kind == TensorKind::ExpertsDown;
}

} // namespace gemma
} // namespace lsxcommon

Body order (each step mirrors the identically-named block in `ConvertQwenModel`,
`qwen_convert.cpp:448-733`):

1. `scan_directory(input_path)`; derive layer count from classified names; cross-check vs topology.
2. `integrity::VerifyAllTensorReads`.
3. `integrity::CheckTensorCoverage(generate_gemma_expected_names(top), present, "gemma")`
   (extra present names = vision/audio → warn only).
4. `integrity::CheckLayerContiguity`, geometry `CheckGeometryFields` (embed shape ↔ vocab/hidden,
   experts.gate_up dim0 ↔ num_experts).
5. Global pass: embed → `global.arrow` (raw BF16 record, PinnedSchema); final norm appended.
6. Per-layer pass: all non-NVFP4 kinds → `layer_N.arrow` (raw records, dtype preserved: BF16/F32).
7. Per-layer expert pass: read `experts.gate_up_proj` `[E, 2*I, H]` and `experts.down_proj`
   `[E, H, I]`; slice per expert e; quantize each slice via `gpu::quantize_tensor_gpu`; pack
   w1=gate_up slice, w2=down slice, w3 left empty (ExpertSchema requires the column — write zero
   bytes like DeepSeek's two-matrix experts do); write
   `<root>/logestix/experts/layer_<l>/exp_<e>.arrow` through the same ExpertSchema writer the
   GLM/DeepSeek converters use (`RepackRoutedExperts` path in `converter.cpp`).
8. Tokenizer: `integrity::BuildAndVerifyTokenizer(<input>/tokenizer.json, pinned_dir,
   TokenizerSpecialIds{true, true, true})`.
9. VRAM: `EstimateVram(inventory, predicate=is_nvfp4_kind, mem_class=expert_files)` →
   `WriteGemmaModelIndex(output_root, top)` with `"format": "logestix-gemma"`.
10. `VerifyConvertedModel(output_root)`; propagate status.

```cpp
// libs/lsxcommon/src/gemma_inference.cu  (kernel set grows in Tasks 6-8)
#include <cuda_bf16.h>
#include <cuda_fp16.h>
#include <cuda_fp4.h>

#include "lsxcommon/gemma4_inference_load.h"

namespace lsxcommon {
namespace gemma {

namespace {
__device__ __forceinline__ __half bf16_bits_to_half(uint16_t bits)
{
    float f;
    unsigned int wide = static_cast<unsigned int>(bits) << 16;
    asm("mov.f32 %0, %1;" : "=f"(f) : "r"(wide));
    return __float2half(f);
}
} // namespace

__global__ void gemma_bf16_to_half_inplace_kernel(uint16_t *buf, long long n)
{
    long long i = static_cast<long long>(blockIdx.x) * blockDim.x + threadIdx.x;
    if (i < n) buf[i] = __half_as_ushort(bf16_bits_to_half(buf[i]));
}

cudaError_t GemmaBf16ToHalfInPlace(uint16_t *d_buf, int64_t numel, cudaStream_t stream)
{
    if (!d_buf || numel <= 0) return cudaErrorInvalidValue;
    if (reinterpret_cast<uintptr_t>(d_buf) % 16 != 0) return cudaErrorInvalidValue;
    int block = 256;
    long long grid = (numel + block - 1) / block;
    gemma_bf16_to_half_inplace_kernel<<<static_cast<int>(grid), block, 0, stream>>>(
        d_buf, numel);
    return cudaGetLastError();
}

} // namespace gemma
} // namespace lsxcommon
```

weights `softmax(sel_logits)[i] * *lw.d_router_scale * lw.d_per_expert_scale[idx[i]]` (RMW-free —
each thread writes its own slot).
- Stack: for each selected expert: `ensure_gemma_expert_resident` → `cudaMemcpyAsync` packed payload
into persistent device staging buffers (allocated once per Infer, sized for one expert:

`sum_i weight_i * down @ act(gate_up @ x_i)` into d_out. Deterministic accumulation ORDER: experts
processed sequentially in selected-index order (no atomics).
- Dense MLP: cuBLAS `cublasGemmsEx` (FP16 in/out, FP32 compute) gate/up → gelu_tanh kernel → down.
