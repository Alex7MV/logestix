# Qwen3.5-9B Real-Weight Completion — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task. Subagent dispatch is FORBIDDEN by AGENTS.md

> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the real Qwen3.5-9B checkpoint, pass its SelfCheck, and
capture + land its FSI/CODE/DET goldens and perf baseline so the real-weight
gates run green.

**Architecture:** The model code already exists on `main`
(`qwen_dense_model.{h,cpp}`, registry `qwen3.5-9b`, converter auto-detect at
`qwen_dense_convert.cpp:385`) on the shared `QwenBaseModel` dense contour that
the just-completed Qwen3.8-27B uses. This plan only runs the operational path
and adds one `OVERRIDES` row to the three capture tools.

**Tech Stack:** C++20/CMake presets, `lsxforge`/`lsxfabric`/`lsxcli`,
`lsxbenchmark`, Catch2 v3, Python 3 + transformers + torch.

**Design doc:** `docs/superpowers/specs/2026-10-01-qwen3.5-9b-realweight-design.md`

## Global Constraints

- Branch: `feat/model-Qwen3.5-9B` (already created off `main`).
- Builds: `build/linux-debug` for tests; `build/linux-release-znver4-aocc` for
  conversion and perf. If a build dir is missing, configure first with
  `cmake --preset linux-debug` / `cmake --preset linux-release-znver4-aocc`.
- GPU exclusivity: **one GPU job at a time**. Perf is last.
- Vault root: `/mnt/llm_models/models`; model root is
  `/mnt/llm_models/models/Qwen3.5-9B` (pass the root, not `logestix/`).
- CUDA reference: mirrored docs at `/home/alexmv2025/projects/cuda/docs`
  (consult before any kernel edit).
- No subagents. Logging via spdlog in C++. English commit messages
  (`docs:`/`feat:`/`test:`/`fix:`).
- Do not loosen a gate: a divergence is a finding to investigate.
- Committed artifacts: only `tests/fixtures/{fsi,code,det}/qwen3.5-9b.json` and
  the `tests/perf/perf_baselines.json` entry. Converted weights and `raw`
