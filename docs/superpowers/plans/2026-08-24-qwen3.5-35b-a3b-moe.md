# Qwen3.5-35B-A3B (MoE) Ingestion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add MoE model `qwen3.5-35b-a3b` (Qwen3_5MoeForConditionalGeneration): converter (`--qwen35moe`), on-demand expert loader with LRU device cache, CUDA router/expert kernels, model class in registry, lifecycle strategy, TDD test suite.

**Architecture:** Self-contained MoE pipeline (Approach A). Attention/RoPE/gated-delta kernels are reused verbatim from `qwen_inference.cu` — they are fully runtime-parameterized by `qwen::QwenTopology` (verified: no 9B constants inside kernels). New code covers only the MoE FFN path (router top-8 softmax+renorm, fused-expert NVFP4 decode SwiGLU, shared expert + scalar gate), an on-demand mmap expert store with LRU device-slot cache (GLM pattern), and a generation driver whose layer loop mirrors `RunQwenGeneration` but swaps the MLP call site for the MoE stack. Spec: `docs/superpowers/specs/2026-08-24-qwen3.5-35b-a3b-moe-ingestion-design.md`.

**Tech Stack:** C++20, CUDA 13.3 (Blackwell sm_120/121 only), Apache Arrow 25 (IPC), simdjson, absl::Log/spdlog via `lsxcommon::log`, Catch2 v3, CMake presets (`linux-debug`).

## Global Constraints

- Frozen geometry: hidden=2048, layers=40, experts=256, top_k=8, moe_inter=512, shared_inter=512, heads=16, kv_heads=2, head_dim=256, linear nk=16/kd=128/nv=32/vd=128/conv=4, vocab=248320, eos=248044, rms_norm_eps=1e-6, partial_rotary_factor=0.25, rope_theta=1e7. Full attention exactly at layer indices where `index % 4 == 3`.
- `static_assert(kTopK <= kNumExperts)` mandatory. No static_assert on hidden==heads*head_dim (16*256≠2048); relational asserts only (27B pattern).
- Norms/biases/router gate/shared_expert_gate stay BF16→FP16 (NEVER quantized). Quantized NVFP4: all attention projections, embeddings, lm_head, fused expert weights, shared expert weights.
- HF parity semantics (verified against transformers 5.15.1 `modeling_qwen3_5_moe.py`):
  - Fused `gate_up_proj[e]` is `[2*I, H]`; **gate = rows [0,I), up = rows [I,2I)**.
  - Router: softmax over ALL logits in fp32 → top-k on probabilities → renormalize by sum. No bias, no scaling factor.
  - MoE out = routed_output + sigmoid(shared_expert_gate(h)) * shared_mlp(h).
  - RMSNorm offset form `rmsnorm(x)*(1+w)` (matches existing `rmsnorm_offset_kernel`).
  - MTP tensors converted+stored, NOT applied in Infer.
- All logging through `lsxcommon::log` (no printf/cout). All model paths through `lsx_common metadata authority`: converter receives output_root from CLI; loader reads from `ModelInitConfig::model_path`.
- Single `cudaStream_t` for whole generation; no `cudaDeviceSynchronize()` in the loop; shared-memory RMW only by thread 0 behind `__syncthreads()`.
- abseil containers forbidden in any header reachable from `.cu` TU (use std:: there).
- Build/test commands: `cmake --build --preset linux-debug --target <t>` / `ctest --preset linux-debug -R <regex>`.
- Real-checkpoint tests SKIP with return code 4 when `/mnt/llm_models/models/Qwen3.5-35B-A3B` is absent or `LSX_TEST_ALLOW_SYNTHETIC_GEOMETRY` gates fail.
- Passport scope note: `passport.bin` is the fixed GLM↔DeepSeek orchestrator bridge (`lsx_token_translator.h`); format has no qwen slots. Extending it for qwen↔deepseek translation is a separate sub-project — NOT in this plan. IoWorker integration unchanged.
- Git: English commit messages, prefixes `feat:`/`test:`/`fix:`/`refactor:`/`docs:`.

const simdjson::simdjson_result<simdjson::dom::element>
GetI(const simdjson::dom::element &root, const char *key) {
    return root.at_key(key);
}

int IntOf(const simdjson::dom::element &cfg, const char *key, int def) {
    auto v = cfg.at_key(key);
    if (v.error() || v.value().type() != simdjson::dom::element_type::INT64)
        return def;
    return static_cast<int>(v.value().get_int64().value());
}

double DblOf(const simdjson::dom::element &cfg, const char *key, double def) {
    auto v = cfg.at_key(key);
    if (v.error()) return def;
    double d = 0;
    if (v.get(d) == simdjson::error_code::SUCCESS) return d;
    return def;
}

} // namespace

QwenMoeTopology ParseQwenMoeConfig(const std::string &input_dir) {
    QwenMoeTopology top;
    namespace fs = std::filesystem;
    const fs::path cfg_path = fs::path(input_dir) / "config.json";
    std::error_code ec;
    if (!fs::exists(cfg_path, ec)) {
        top.error_msg = "config.json not found: " + cfg_path.string();
        return top;
    }
    simdjson::dom::parser parser;
    simdjson::dom::element root;
    auto err = parser.load(cfg_path.string()).get(root);
    if (err) {
        top.error_msg = "config.json parse error";
        return top;
    }
    // text_config preferred; fall back to flat root (synthetic fixtures).
    simdjson::dom::element cfg = root;
    if (!root.at_key("text_config").error()) root["text_config"].tie(cfg);
    top.hidden_size = IntOf(cfg, "hidden_size", 0);
    top.num_layers = IntOf(cfg, "num_hidden_layers", 0);
    top.vocab_size = IntOf(cfg, "vocab_size", 0);
    top.num_attention_heads = IntOf(cfg, "num_attention_heads", 0);
    top.num_key_value_heads = IntOf(cfg, "num_key_value_heads", 0);
    top.head_dim = IntOf(cfg, "head_dim", 0);
    top.linear_num_key_heads = IntOf(cfg, "linear_num_key_heads", 0);
    top.linear_num_value_heads = IntOf(cfg, "linear_num_value_heads", 0);
    top.linear_key_head_dim = IntOf(cfg, "linear_key_head_dim", 0);
    top.linear_value_head_dim = IntOf(cfg, "linear_value_head_dim", 0);
    top.linear_conv_kernel_dim = IntOf(cfg, "linear_conv_kernel_dim", 4);
    top.intermediate_size = IntOf(cfg, "intermediate_size", 0); // unused for MoE layers
    top.rms_norm_eps = DblOf(cfg, "rms_norm_eps", 1e-6);
    top.partial_rotary_factor = DblOf(cfg, "partial_rotary_factor", 0.25);
    top.rope_theta = DblOf(cfg, "rope_theta", 1e7);
    top.num_experts = IntOf(cfg, "num_experts", 0);
    top.num_experts_per_tok = IntOf(cfg, "num_experts_per_tok", 0);
    top.moe_intermediate_size = IntOf(cfg, "moe_intermediate_size", 0);
    top.shared_expert_intermediate_size =
        IntOf(cfg, "shared_expert_intermediate_size", 0);

bool starts_with(const std::string &n, const char *p) { return n.rfind(p, 0) == 0; }
// extracts trailing ".layers.<N>." index; -1 if absent
int layer_of(const std::string &n) {
    const std::string k = ".layers.";
    auto p = n.find(k);
    if (p == std::string::npos) return -1;
    auto s = n.find_first_not_of(".0123456789", p + k.size() - 1);
    return std::stoi(n.substr(p + k.size(), s - (p + k.size())));
}
} // namespace

ParsedMoeTensor classify_qwen_moe_tensor(const std::string &name) {
    ParsedMoeTensor r;
    r.layer = layer_of(name);
    if (starts_with(name, "mtp.")) { r.kind = MoeTensorKind::Mtp; return r; }
    if (name.find("visual") != std::string::npos) { r.kind = MoeTensorKind::Visual; return r; }
    if (name == "lm_head.weight") { r.kind = MoeTensorKind::LmHead; return r; }
    if (!starts_with(name, "model.language_model.")) return r;
    const std::string rest = name.substr(sizeof("model.language_model.") - 1);

    if (rest == "norm.weight") { r.kind = MoeTensorKind::FinalNorm; return r; }
