# Qwen3.8-27B Model Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Qwen3.8-27B model support by extracting a shared QwenBaseModel base class, deriving Qwen3_5_9BModel and Qwen3_8_27BModel wrappers with compile-time geometry constants, and auto-detecting the model variant in the converter.

**Architecture:** A new QwenBaseModel (in `qwen_base_model.h/cpp`) inherits IModel and holds all shared Load/Infer/Unload/SelfCheck logic. Qwen3_5_9BModel (replaces existing QwenV5Model) and Qwen3_8_27BModel (new) derive from it, providing only compile-time geometry constants + Type(). Converter auto-detects variant from config.json geometry. Geometry validation is non-fatal (logs warning on mismatch) so synthetic tests keep working.

**Tech Stack:** C++20, CUDA 13.2+, Arrow 25.0.0, Catch2 v3.7

```cpp
arrow::Status WriteQwenModelIndex(const std::string &output_root, const QwenTopology &top)
{
    namespace fs = std::filesystem;
    auto dir = fs::path(output_root) / "logestix";
    if (!fs::exists(dir)) {
        auto st = fs::create_directories(dir);
        if (!st) return arrow::Status::IOError("cannot create ", dir.string());
    }

    // Auto-detect model variant from geometry.
    std::string model_name = "Qwen3.5-9B";  // default
    if (top.hidden_size == 5120 && top.num_layers == 64 &&
        top.num_attention_heads == 24 && top.linear_num_value_heads == 48)
        model_name = "Qwen3.8-27B";

    std::ostringstream j;
    j << "{\n"
      << "  \"format\": \"logestix-qwen\",\n"
      << "  \"model\": \"" << model_name << "\",\n"
      << "  \"num_layers\": " << top.num_layers
```

```cpp
#include <catch2/catch_all.hpp>

#include <lsxcommon/model_factory.h>
#include <lsxcommon/qwen_convert.h>
#include <lsxcommon/qwen_inference_load.h>

#include <spdlog/spdlog.h>

#include "qwen_test_fixture.h"

#include <filesystem>

using namespace std::filesystem;

TEST_CASE("Qwen3.8-27B model factory registration and generation")
{
    auto tmp = temp_directory_path() / "qwen_27b_model_test";
    remove_all(tmp);
    create_directories(tmp);

    // Override test config with 27B-like geometry (scaled down for speed).
    auto &cfg = const_cast<qwentest::QwenTestConfig&>(qwentest::TestCfg());
    cfg.model_name = "qwen3.8-27b";
    cfg.hidden_size = 64;
    cfg.intermediate_size = 128;
    cfg.vocab_size = 64;
    cfg.num_layers = 4;
    cfg.num_attention_heads = 2;
    cfg.num_key_value_heads = 1;
    cfg.head_dim = 32;
    cfg.linear_num_key_heads = 2;
    cfg.linear_num_value_heads = 4;
    cfg.linear_key_head_dim = 8;
    cfg.linear_value_head_dim = 8;
    cfg.linear_conv_kernel_dim = 4;
    cfg.layer_types = {
        "linear_attention", "linear_attention", "linear_attention", "full_attention"
    };

    auto tensors = qwentest::BuildSyntheticQwenModel();
    qwentest::WriteSafetensors(tmp, "model.safetensors", tensors);
    qwentest::WriteConfig(tmp);
    REQUIRE(lsxcommon::qwen::ConvertQwenModel(tmp.string(), tmp.string()).ok());

    lsxcommon::ModelInitConfig mcfg;
    mcfg.model_path = tmp.string();
    auto model = lsxcommon::LsxModelFactory::Create(mcfg);
    REQUIRE(model != nullptr);
    CHECK(model->Type() == "qwen3.8-27b");

    bool loaded = model->Load();
    CHECK(loaded);

    lsxcommon::ModelRequest req;
    req.input_ids = {0, 1, 2, 3};
    req.max_gen_tokens = 5;

    auto result = model->Infer(req);
    spdlog::info("[qwen_27b_test] Infer error_msg='{}'", result.error_msg);
    REQUIRE(result.ok);
    CHECK(result.num_tokens > 0);
    CHECK(result.first_gen_tok_id >= 0);

    auto sc = model->SelfCheck(req);
    CHECK(sc.ok);
    CHECK(sc.error_msg.empty());

    model->Unload();
    remove_all(tmp);
}
```
