# Qwen3.8-27B Integration Audit + Perf Baseline — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task (subagent dispatch is FORBIDDEN by AGENTS.md
> — all work runs inline in the main session). Steps use checkbox (`- [ ]`)
> syntax for tracking.

**Goal:** Audit the existing Qwen3.8-27B integration against the 8-stage Model
Ingestion Protocol, convert the real checkpoint into the vault, run the real
selfcheck, and register + measure the perf baseline (max t/s on RTX 5090).

**Architecture:** The model code already exists on the shared `QwenBaseModel`
dense contour (`qwen_dense_27b_model.{h,cpp}`, registry `qwen3.8-27b`,
converter auto-detect at `qwen_dense_convert.cpp:386`). This plan validates
each lifecycle stage, then adds the perf-baseline plumbing following the exact
pattern of the 7 existing entries in `tests/test_perf_baseline.cpp` +
`tests/CMakeLists.txt:1132-1172`.

**Tech Stack:** C++20/CMake presets, Catch2 v3, lsxforge (conversion),
lsxfabric (validation), ctest labels `fast`/`perf`.

**Design doc:** `docs/superpowers/specs/2026-09-12-qwen3.8-27b-audit-design.md`

## Global Constraints

- Audit/verification builds: `linux-debug` preset. Measurement builds:
  `linux-release-znver4-aocc` (operator decision).
- GPU exclusivity: no parallel GPU jobs while converting or measuring
  (AGENTS.md lsxbenchmark rule; conversion and selfcheck also touch the GPU).
- No subagents (AGENTS.md Autonomous Mode).
- Perf test protocol must match existing entries exactly: prompt
  `"The capital of France is"`, `max_gen` 2048, `TIMEOUT 1200`,
  `SKIP_RETURN_CODE 4`, `LABELS perf`, literal `add_test`/`set_tests_properties`
  calls (guard `test_ctest_labels_guard` statically parses them).
- Commit prefixes: `fix:`, `feat:`, `test:`, `docs:`; English messages.
- All logging via spdlog; no comments unless refactoring requires keeping docs.
- abseil format discipline: printf-style `%s/%d/%u/%f` in
  `absl::StrFormat` (never `{}`) — guarded by `tests/test_absl_format_guard.cpp`.
