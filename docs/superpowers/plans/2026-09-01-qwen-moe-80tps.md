# Qwen3.5-35B-A3B 80 tok/s (device-driven decode) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise the DEFAULT decode throughput of Qwen3.5-35B-A3B on RTX 5090 (Linux, AOCC release, full residency) from 63.5 to >= 80 tok/s via a batched TC routed-expert chain (no per-layer host handshake) and device-side token feed.

**Architecture:** Two levers inside the existing single-stream decode driver (`RunQwenMoeGeneration`): (1) a batched tensor-core NVFP4 routed chain — one `grid.z = K` launch set per layer instead of K=8 sequential per-slot chains, with the slot table composed on device (no router readback at full residency); (2) device-side token feed (kimi round-25 pattern) removing the per-step argmax D2H + blocking sync. Per-slot math is bit-identical to the legacy chain (same TC kernels, same fp32 accumulation order); the legacy chain stays as the fallback and remains the default behavior until full residency + fast_math readiness trips.

**Tech Stack:** CUDA 13.3 (sm_120a/121a only, `kind::mxf4nvf4` MMA), C++20, Catch2 v3, CMake presets (`linux-release-znver4-aocc`).

**Spec:** `docs/superpowers/specs/2026-09-01-qwen-moe-80tps-design.md`

## Global Constraints

- Bit-exact contract (STRICT): every engaged config keeps run-to-run bit reproducibility; selfcheck x3 " Paris" deterministic; numeric class (TC W4A4) unchanged.
- Legacy per-slot chain must stay bit-identical to today's default when the new path is not engaged.
- Default production routing (no env flags) must reach >= 80 tok/s.
- Protocol invariants (AGENTS.md): ONE stream end-to-end, no `cudaDeviceSynchronize` in the decode loop; single-stream invariant; shared-memory RMW only via thread 0 under `__syncthreads()`.
- Compilation: `.cu` files compile under NVCC — no abseil containers in any header reachable from `.cu` TUs. No comments unless the file already carries them (match the file's comment style). spdlog for logging, never printf (the existing `fprintf(stderr, "[AUDIT]...")` diagnostic block is pre-existing and stays).
- Windows model-test policy: do NOT run qwen model tests on Windows; this plan targets the Linux/5090 box. Synthetic-geometry tests are Windows-safe but the perf/selfcheck acceptance runs on Linux.
- Measurement discipline (round-18b lesson): after any `git checkout` of sources, full rebuild before measuring; perf comparisons interleaved same-session, >= 3 alternations.
- Test environment gates: `LSX_TEST_ALLOW_SYNTHETIC_GEOMETRY=1` for synthetic checkpoints; `SetQwenTcFastMath(true/false)` for TC-path kernel tests (do not leave the process toggle set across tests — restore in the same test).

```cpp
// Batch split-K finalize: y[slot][i] = sum_z partials[slot*split_k+z][i]
// * scale(col). Deterministic ascending z order == legacy per-z sum.
__global__ void TcSplitKFinalizeBatch(const float *__restrict__ partials,
                                      __half *__restrict__ y, int seq, int N,
                                      int split_k,
                                      const QwenTcBatchSlot *__restrict__ slots,
                                      int k_slots, bool seg13)
{
    const int64_t i = static_cast<int64_t>(blockIdx.x) * blockDim.x +
                      threadIdx.x;
    const int64_t total = static_cast<int64_t>(seq) * N * k_slots;
    if (i >= total) return;
    const int slot = static_cast<int>(i / (static_cast<int64_t>(seq) * N));
    const int64_t local = i - static_cast<int64_t>(slot) * seq * N;
    float sum = 0.f;
    const int64_t zbase = static_cast<int64_t>(slot) * split_k * seq * N;
    for (int z = 0; z < split_k; ++z)
        sum += partials[zbase + static_cast<int64_t>(z) * seq * N + local];
    const int col = static_cast<int>(local % N);
    const float ws = seg13 ? (col < N / 2 ? slots[slot].gs1 : slots[slot].gs3)
                           : slots[slot].gs2;
    y[static_cast<int64_t>(slot) * seq * N + local] = __float2half(sum * ws);
}
```

```cpp
int QwenTcBatchSplitK(int K, int N)
{
    // Mirror of TcGemmDispatch's split-K rule (seq==1, !acc): same inputs ->
    // same split_k on both the single-slot and batched paths.
    if (K < 2048 || (K % 512) != 0) return 1;
    const int grid_x = (N + kTileN - 1) / kTileN;
    if (grid_x >= 192) return 1;
    for (int cand : {8, 4, 2}) {
        if ((K / 64) % cand == 0 && grid_x * cand >= 96) return cand;
    }
    return 1;
}

bool TcRuntimeSupported()
{
    int dev = 0;
    if (cudaGetDevice(&dev) != cudaSuccess) return false;
    cudaDeviceProp prop{};
    if (cudaGetDeviceProperties(&prop, dev) != cudaSuccess) return false;
    return prop.major == 12;
}
```

```cpp
// Slot-major batched swiglu-quant: gate ygu[s*2I + j], up ygu[s*2I + I + j]
// -> h[s*I + j] + NVFP4 pack/scales at slot offsets. Per-16-group math is
// the exact clone of qwen_swiglu_precise_quant_kernel (bit-identical).
__global__ void moe_swiglu_quant_batch_kernel(const __half *__restrict__ ygu,
                                              int k_slots, int I,
                                              __half *__restrict__ h,
                                              uint8_t *__restrict__ packed,
                                              uint8_t *__restrict__ scales)
{
    const int64_t groups_total =
        static_cast<int64_t>(k_slots) * ((I + 15) / 16);
    const int64_t g = static_cast<int64_t>(blockIdx.x) * blockDim.x +
                      threadIdx.x;
    if (g >= groups_total) return;
    const int s = static_cast<int>(g / ((I + 15) / 16));
    const int j0 = static_cast<int>((g - static_cast<int64_t>(s) *
                                               ((I + 15) / 16)) * 16);
    const int len = (j0 + 16 <= I) ? 16 : (I - j0);

    float vals[16];
    float absmax = 0.0f;
    for (int i = 0; i < len; ++i) {
        const float gv = __half2float(ygu[static_cast<int64_t>(s) * 2 * I + j0 + i]);
        const float uv = __half2float(ygu[static_cast<int64_t>(s) * 2 * I + I + j0 + i]);
        const float sig = __fdiv_rn(1.0f, __fadd_rn(1.0f, expf(-gv)));
        const __half hv = __float2half(__fmul_rn(sig, __fmul_rn(gv, uv)));
        h[static_cast<int64_t>(s) * I + j0 + i] = hv;
        vals[i] = __half2float(hv);
        absmax = fmaxf(absmax, fabsf(vals[i]));
    }
    const uint8_t sb = lsxcommon::nvfp4::FloatToE4m3P2(absmax * (1.0f / 6.0f));
    scales[g] = sb;
    const float inv_s = gpu::nvfp4::E4M3ScaleToFloat(sb);
    const float inv = inv_s > 0.0f ? 1.0f / inv_s : 0.0f;
    const int64_t slot_base = static_cast<int64_t>(s) * I;
    for (int i = 0; i < len; i += 2) {
        const uint8_t lo = lsxcommon::kernels::QuantizeE2m1TieUp(vals[i] * inv);
        const uint8_t hi = (i + 1 < len)
                               ? lsxcommon::kernels::QuantizeE2m1TieUp(
                                     vals[i + 1] * inv)
                               : 0;
        packed[(slot_base + j0 + i) / 2] = static_cast<uint8_t>((hi << 4) | lo);
    }
}
```
