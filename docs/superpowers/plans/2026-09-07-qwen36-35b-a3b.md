# Qwen3.6-35B-A3B Ingestion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking. NOTE (AGENTS.md, Autonomous Mode): Task-subagents are FORBIDDEN in
> this repo — execute every task inline in the main session.

**Goal:** Integrate Qwen3.6-35B-A3B (registry `qwen3.6-35b-a3b`, format
`logestix-qwen36moe`) per the Model Ingestion Protocol: a shared converter core with 3.5,
its own frozen passport and model class on the shared qwen_moe runtime graph, TDD,
without new CUDA kernels.

**Architecture:** The 3.6 architecture is identical to 3.5 (`qwen3_5_moe`), therefore:
the converter — a shared `ConvertQwenMoeModelCommon(spec)` + two thin wrappers;
the model — the shared base `QwenMoeModelBase` (in `qwen_moe_model.h`) with leaf classes
`Qwen35MoeModel`/`Qwen36MoeModel` (their own kType, their own frozen gate, their own
`Infer` with `LsxFastMathScope`). Loader/kernels/generation-driver — family infra,
unchanged.

**Tech Stack:** C++20, CUDA 13.x (Blackwell sm_120/121), Arrow 25 (FetchContent),
simdjson, abseil, Catch2 v3, spdlog, CMake presets/Ninja.

**Spec:** `docs/superpowers/specs/2026-09-07-qwen36-35b-a3b-ingestion-design.md`

## Global Constraints

- Branch: `feat/qwen36-35b-a3b` (already created).
- Build: the existing config `build/linux-release-znver4-aocc`
  (AOCC 5.2.0, `-j 160`). All build/test commands — from the repo root
  (this checkout).
- C++20; no `std::cout`/`printf` (spdlog only); comments — only
  preserving/adapting existing ones; no new emoji.
- Naming guard: scheme `<family>_<type>[_<variant>]_<role>`; the variant vocabulary
  is extended with `36` in the same commit as the new files.
- Independence guard: a unique passport `qwen_moe_36_constants.h` /
  `lsxcommon::qwen_moe_36::frozen`; the consumer `qwen_moe_36_model.cpp` in the same
  commit as its `Infer`.
- The 3.5 converter output must stay byte-identical (record_bos=false,
  the previous format/model lines). Regression shield: `test_qwen_moe_convert` (119
  assertions) + the determinism test.
- abseil containers are forbidden in headers transitively reachable from `.cu`.
- Windows-only API in tests — under `#ifdef _WIN32` (reference: `_putenv_s` in
  `qwen_moe_test_fixture.h::MoeSetEnv`).
- Inference/inference tests — exclusive runs (resource policy); converting
  67 GB is not parallelized with other heavy tasks.

```cpp
// Appends an explicit bos_token_id into the synthetic text_config (mirrors
// the real Qwen3.6-35B-A3B config.json layout).
void PatchConfigBos(const fs::path &dir, int bos_id)
{
    const fs::path cfg = dir / "config.json";
    std::ifstream f(cfg);
    std::stringstream ss;
    ss << f.rdbuf();
    std::string j = ss.str();
    const std::string needle = ",\"hidden_act\":\"silu\"";

    j.replace(pos, needle.size(),
              ",\"hidden_act\":\"silu\",\"bos_token_id\":" +
                  std::to_string(bos_id));
    std::ofstream g(cfg, std::ios::trunc);
    g << j;
}

std::string ReadIndex(const fs::path &out)
{
    std::ifstream f(out / "logestix" / "model.index.json");
    std::stringstream ss;
    ss << f.rdbuf();
    return ss.str();
}
```

```cpp
#include "lsxcommon/qwen_moe_36_convert.h"

#include "qwen_moe_36_constants.h"
#include "lsxcommon/qwen_moe_convert.h"

#include <absl/strings/str_format.h>

#include <string>

namespace lsxcommon::qwen_moe_36 {
namespace {

// Cross-checks parsed config against the 3.6 frozen passport. Returns false
// and fills `why` on mismatch (etalon: qwen_moe_convert.cpp
// check_frozen_geometry).
bool check_frozen_geometry_36(const qwen_moe::QwenMoeTopology &top,
                              std::string &why)
{
    using namespace frozen;
    auto bad = [&why](const char *field, int got, int want) {
        why = absl::StrFormat("%s: got %d, want %d", field, got, want);
        return false;
    };
    if (top.hidden_size != kHidden)
        return bad("hidden_size", top.hidden_size, kHidden);
    if (top.num_layers != kLayers)
        return bad("num_hidden_layers", top.num_layers, kLayers);
    if (top.num_attention_heads != kHeads)
        return bad("num_attention_heads", top.num_attention_heads, kHeads);
    if (top.num_key_value_heads != kKVHeads)
        return bad("num_key_value_heads", top.num_key_value_heads, kKVHeads);
    if (top.head_dim != kHeadDim)
        return bad("head_dim", top.head_dim, kHeadDim);
    if (top.linear_num_key_heads != kLinearNumKeyHeads)
        return bad("linear_num_key_heads", top.linear_num_key_heads,
                   kLinearNumKeyHeads);
    if (top.linear_num_value_heads != kLinearNumValueHeads)
        return bad("linear_num_value_heads", top.linear_num_value_heads,
                   kLinearNumValueHeads);
    if (top.linear_key_head_dim != kLinearKeyHeadDim)
        return bad("linear_key_head_dim", top.linear_key_head_dim,
                   kLinearKeyHeadDim);
    if (top.linear_value_head_dim != kLinearValueHeadDim)
        return bad("linear_value_head_dim", top.linear_value_head_dim,
                   kLinearValueHeadDim);
    if (top.vocab_size != kVocab)
        return bad("vocab_size", top.vocab_size, kVocab);
    if (top.num_experts != kNumExperts)
        return bad("num_experts", top.num_experts, kNumExperts);
    if (top.num_experts_per_tok != kTopK)
        return bad("num_experts_per_tok", top.num_experts_per_tok, kTopK);
    if (top.moe_intermediate_size != kMoeIntermediate)
        return bad("moe_intermediate_size", top.moe_intermediate_size,
                   kMoeIntermediate);
    if (top.shared_expert_intermediate_size != kSharedIntermediate)
        return bad("shared_expert_intermediate_size",
```

```cpp
               : std::filesystem::path(lsxcommon::lsx_model_models_dir()) /
                     "Qwen3.6-35B-A3B";
}

std::vector<int32_t> EncodeSelfCheckPrompt(lsxcommon::ArrowTokenizerDb &tok)
{
    const char *prompt = "The capital of France is";
    std::vector<int32_t> ids(512, 0);
    size_t cap = ids.size();
    const int32_t n = lsxcommon::arrow_tokenizer_encode(
        tok, prompt, std::strlen(prompt), ids.data(), &cap);
    if (n <= 0) return {};
    ids.resize(static_cast<size_t>(n));
    return ids;
}

TEST_CASE("Qwen3.6-35B-A3B SelfCheck: 'The capital of France is' -> 'Paris', "
          "stress cycles with bit-exact deterministic logits",
          "[qwen36][model][selfcheck][real-model]")
{
    const std::filesystem::path model_dir = Qwen36ConvertedPath();
    if (!std::filesystem::exists(model_dir / "logestix" / "pinned"))
        SKIP("Qwen3.6-35B-A3B converted model directory not present");

    lsxcommon::ModelInitConfig cfg;
    cfg.model_path = model_dir.string();
    auto m = lsxcommon::LsxModelFactory::Create(cfg);
    REQUIRE(m != nullptr);
    // Auto-detection path: index "model" -> "qwen3.6-35b-a3b".
    REQUIRE(m->Type() == "qwen3.6-35b-a3b");
    REQUIRE(m->Load());

    const std::vector<int32_t> ids = EncodeSelfCheckPrompt(m->Tokenizer());
    REQUIRE(ids.size() > 0);

    lsxcommon::ModelRequest req;
    req.input_ids = ids;
    req.max_gen_tokens = 2;

    auto sc0 = m->SelfCheck(req);
    REQUIRE(sc0.ok);
    REQUIRE(sc0.selfcheck_passed);
    REQUIRE(sc0.first_gen_text == "Paris");
    REQUIRE(!sc0.final_logits.empty());

    const std::vector<float> &ref_logits = sc0.final_logits;
    const int32_t ref_first = sc0.first_gen_tok_id;
    const int cycles = SelfCheckCycles();

    for (int i = 1; i < cycles; ++i) {
        auto sc = m->SelfCheck(req);
        REQUIRE(sc.ok);
        REQUIRE(sc.selfcheck_passed);
        CHECK(sc.first_gen_text == "Paris");
        CHECK(sc.first_gen_tok_id == ref_first);
        CHECK(sc.final_logits.size() == ref_logits.size());
        CHECK(std::memcmp(sc.final_logits.data(), ref_logits.data(),
                          ref_logits.size() * sizeof(float)) == 0);
    }

    m->Unload();
}
```
