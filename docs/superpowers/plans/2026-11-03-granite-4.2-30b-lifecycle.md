# granite-4.2-30b Full Lifecycle Re-Verification — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the real `granite-4.2-30b` checkpoint into the NVFP4 vault and re-verify every model-lifecycle stage (SelfCheck, FSI, CODE, DET, tool round-trip, perf/r3, launch smoke) with a stage-9 report.

**Architecture:** The `granite` family is already implemented (`granite_dense_convert/load/inference/model`, `granite_tool_format`, `lsxforge --granite`). This plan does not add a new architecture; it exercises the existing code on real weights, treats any RED gate as a real defect (TDD: failing regression test before fix), re-seeds the two stale perf rows, and records the evidence in the report + docs.

**Tech Stack:** C++20, CUDA 13.4 (Blackwell sm_120), CMake presets (`linux-release-znver4-aocc`, `linux-debug`), Catch2 v3.16.1, Apache Arrow IPC, NVFP4.

## Global Constraints

- Target architecture: Blackwell (CC 12.0/12.1) only. CUDA Toolkit 13.4 (minimum 13.2+).
- Model vault root: `/mnt/fast_storage/huggingface` (Linux default `kModelRootBase`); converted trees live in `<root>/<Model>/logestix/`. Scratch on `/mnt/fast_storage/tmp`.
- Release preset for gates/perf: `linux-release-znver4-aocc` (AOCC clang 17, `NDEBUG`, LTO). Debug preset for debug-only tests: `linux-debug`.
- Perf rows are written by the harness (`tests/test_perf_baseline.cpp`); never hand-edit `tokens_per_sec`.
- Strict GPU exclusivity for `lsxbenchmark` / perf: no other GPU workload runs during Task 5.
- Logging via spdlog only; no `std::cout`/`printf` in product code. No comments unless asked.
- TDD: every RED gate that reveals a defect gets a failing regression test before the fix.
- Commit only on explicit request from the operator; this plan assumes commit steps were authorized for the branch.
- Working directory: `/mnt/fast_storage/projects/cuda/logestix`; branch `feat/granite-4.2-30b-lifecycle`.
