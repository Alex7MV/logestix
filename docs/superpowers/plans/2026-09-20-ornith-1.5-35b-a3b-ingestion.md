# Ornith-1.5-35B-A3B Ingestion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (inline, no subagents — AGENTS.md forbids Task subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ingest the MLX-exported `Ornith-1.5-35B-A3B` checkpoint (architecture-identical Qwen3.5-MoE fine-tune) as its own `ornith` family, end-to-end, targeting `SelfCheck("The capital of France is") -> "Paris"`.

**Architecture:** A standalone MLX-layout converter produces the unified `<root>/logestix/` arrow layout; a duplicated MoE family layer (`ornith_moe_{constants,load,inference,model}`) consumes it while reusing the generic `qwen_inference.*` kernel layer; the model is registered as `ornith-1.5-35b-a3b` and never borrows another model's frozen geometry.

**Tech Stack:** C++20 / C23, CUDA (CC 12.0/12.1), Arrow, NVFP4, CMake presets, Catch2 v3, ctest labels.

## Global Constraints

- Branch: `feat/ornith-1.5-35b-a3b-ingestion` (already created; design committed at `366c671`).
- Architecture only Blackwell `compute_120 / compute_121`; no sm_90/sm_80.
- NVFP4 only through the model-neutral `lsx_nvfp4` (`RunLsxNvfp4Gemm` / `LsxTcFastMath`); never family-owned dispatch.
- Norms/biases/router/conv1d/A_log/dt_bias are never quantized; they stay BF16/F32.
- No abseil container headers reachable from `.cu`/`.cuh`; device TUs use `std::`.
- Logging only via spdlog; `absl::StrFormat` is printf-style (`%s/%d`), never `{}`.
- Every new test gets a ctest label in the same commit; convert tests get a bounded TIMEOUT (≤600 s, use 120); selfcheck/perf targets get `SKIP_RETURN_CODE 4`.
- Model files must be named `ornith_moe_<role>[_<subsystem>]`; guard token sets extended in the same commit.
- Commit style: `feat:`/`fix:`/`test:`/`build:`/`docs:`. Commit only at the end of each task.
- Frozen geometry (from `/mnt/llm_models/models/Ornith-1.5-35B-A3B-MLX/config.json`): hidden=2048, layers=40, full_attention at `i%4==3`, heads=16, kv=2, head_dim=256, linear 16/32/128/128, conv_kernel=4, vocab=248320, experts=256, top-8, moe_i=512, shared_i=512, rms_eps=1e-6, partial_rotary=0.25, rope_theta=1e7, bos=248044.
- Converted root: `/mnt/llm_models/models/Ornith-1.5-35B-A3B-MLX` (vault dir keeps the `-MLX` suffix; index `model` field is `Ornith-1.5-35B-A3B`).

inline std::vector<FakeTensor> BuildSyntheticOrnithTensors()
{
    const auto &c = OrnithCfg();
    const int H = c.hidden_size;
    const int V = c.vocab_size;
    const int E = c.num_experts;
    const int I = c.moe_intermediate_size;
    const int SI = c.shared_expert_intermediate_size;
    const int KD = c.linear_num_key_heads * c.linear_key_head_dim;
    const int VD = c.linear_num_value_heads * c.linear_value_head_dim;
    const int CD = KD * 2 + VD;
    const int NH = c.num_attention_heads * c.head_dim * 2;  // gate doubled
    const int KV = c.num_key_value_heads * c.head_dim;

    auto weight_pattern = [](int64_t i) {
        return ((static_cast<float>(i * 37 % 251)) / 251.0f) - 0.5f;
    };

    std::vector<FakeTensor> t;
    t.push_back({"language_model.model.embed_tokens.weight", "BF16", {V, H},
                 MakeBf16(V * H)});
    t.push_back({"language_model.lm_head.weight", "BF16", {V, H},
                 MakeBf16(V * H)});
    t.push_back({"language_model.model.norm.weight", "BF16", {H},
                 MakeBf16Values(H, [](int64_t i) { return (float)i * 0.01f; })});

    for (int l = 0; l < c.num_layers; ++l) {
        const std::string lp =
            "language_model.model.layers." + std::to_string(l) + ".";
        const bool full = c.layer_types[l] == "full_attention";
        t.push_back({lp + "input_layernorm.weight", "BF16", {H}, MakeBf16(H)});
        t.push_back({lp + "post_attention_layernorm.weight", "BF16", {H},
                     MakeBf16(H)});
        if (full) {
            const auto fa = lp + "self_attn.";
            t.push_back({fa + "q_proj.weight", "BF16", {NH, H}, MakeBf16(NH * H)});
            t.push_back({fa + "k_proj.weight", "BF16", {KV, H}, MakeBf16(KV * H)});
            t.push_back({fa + "v_proj.weight", "BF16", {KV, H}, MakeBf16(KV * H)});
            t.push_back({fa + "o_proj.weight", "BF16",
                         {H, c.num_attention_heads * c.head_dim},
                         MakeBf16(H * c.num_attention_heads * c.head_dim)});
            t.push_back({fa + "q_norm.weight", "BF16", {c.head_dim},
                         MakeBf16(c.head_dim)});
            t.push_back({fa + "k_norm.weight", "BF16", {c.head_dim},
                         MakeBf16(c.head_dim)});
        } else {
            const auto la = lp + "linear_attn.";
            t.push_back({la + "in_proj_qkv.weight", "BF16", {CD, H},
                         MakeBf16(CD * H)});
            t.push_back({la + "in_proj_a.weight", "BF16",
                         {c.linear_num_value_heads, H},
                         MakeBf16(c.linear_num_value_heads * H)});
            t.push_back({la + "in_proj_b.weight", "BF16",
                         {c.linear_num_value_heads, H},
                         MakeBf16(c.linear_num_value_heads * H)});
            t.push_back({la + "in_proj_z.weight", "BF16", {VD, H},
                         MakeBf16(VD * H)});
            t.push_back({la + "out_proj.weight", "BF16", {H, VD},
                         MakeBf16(H * VD)});
            // MLX conv1d layout: [C, K, 1].
            t.push_back({la + "conv1d.weight", "BF16",
                         {CD, c.linear_conv_kernel_dim, 1},
                         MakeBf16(CD * c.linear_conv_kernel_dim)});
            t.push_back({la + "norm.weight", "BF16",
                         {c.linear_value_head_dim},
                         MakeBf16(c.linear_value_head_dim)});
            t.push_back({la + "A_log", "BF16", {c.linear_num_value_heads},
                         MakeBf16(c.linear_num_value_heads)});
            t.push_back({la + "dt_bias", "BF16", {c.linear_num_value_heads},
                         MakeBf16(c.linear_num_value_heads)});
        }
        // MLX stacked experts: [E, I, H] gate/up, [E, H, I] down.
        t.push_back({lp + "mlp.gate.weight", "BF16", {E, H},
                     MakeBf16Values(E * H, weight_pattern)});
        t.push_back({lp + "mlp.switch_mlp.gate_proj.weight", "BF16", {E, I, H},
                     MakeBf16Values(static_cast<int64_t>(E) * I * H,
                                    weight_pattern)});
        t.push_back({lp + "mlp.switch_mlp.up_proj.weight", "BF16", {E, I, H},
                     MakeBf16Values(static_cast<int64_t>(E) * I * H,
                                    weight_pattern)});
        t.push_back({lp + "mlp.switch_mlp.down_proj.weight", "BF16", {E, H, I},
                     MakeBf16Values(static_cast<int64_t>(E) * H * I,
                                    weight_pattern)});
        t.push_back({lp + "mlp.shared_expert.gate_proj.weight", "BF16", {SI, H},
                     MakeBf16Values(SI * H, weight_pattern)});
        t.push_back({lp + "mlp.shared_expert.up_proj.weight", "BF16", {SI, H},
                     MakeBf16Values(SI * H, weight_pattern)});
        t.push_back({lp + "mlp.shared_expert.down_proj.weight", "BF16", {H, SI},
                     MakeBf16Values(H * SI, weight_pattern)});
        t.push_back({lp + "mlp.shared_expert_gate.weight", "BF16", {1, H},
                     MakeBf16Values(H, [](int64_t i) {
                         return -0.5f + (float)i * 0.01f;
                     })});
    }
    return t;
}

ParsedOrnithTensor classify_ornith_moe_tensor(const std::string &name)
{
    ParsedOrnithTensor r;
    if (name.rfind("mtp.", 0) == 0) {
        r.kind = OrnithMoeTensorKind::Mtp;
        return r;
    }
    if (name.find("visual") != std::string::npos) {
        r.kind = OrnithMoeTensorKind::Visual;
        return r;
    }
    if (name == "language_model.lm_head.weight") {
        r.kind = OrnithMoeTensorKind::LmHead;
        return r;
    }
    const std::string kPrefix = "language_model.model.";
    if (name.rfind(kPrefix, 0) != 0)
        return r;
    const std::string rest = name.substr(kPrefix.size());
    if (rest == "embed_tokens.weight") {
        r.kind = OrnithMoeTensorKind::Embed;
        return r;
    }
    if (rest == "norm.weight") {
        r.kind = OrnithMoeTensorKind::FinalNorm;
        return r;
    }
    std::string body = rest;
    const std::string kLayers = "layers.";
    if (rest.rfind(kLayers, 0) == 0) {
        const auto digits_start = kLayers.size();
        const auto digits_end = rest.find('.', digits_start);
        if (digits_end == std::string::npos)
            return r;

            std::stoi(rest.substr(digits_start, digits_end - digits_start));
        body = rest.substr(digits_end + 1);

        {"post_attention_layernorm.weight", K::PostNorm},

        {"self_attn.v_proj.weight", K::FullAttnV},
        {"self_attn.o_proj.weight", K::FullAttnO},
        {"self_attn.q_norm.weight", K::FullAttnQNorm},
        {"self_attn.k_norm.weight", K::FullAttnKNorm},
        {"linear_attn.in_proj_qkv.weight", K::LinearAttnQkv},
        {"linear_attn.in_proj_z.weight", K::LinearAttnZ},
        {"linear_attn.in_proj_b.weight", K::LinearAttnB},
        {"linear_attn.in_proj_a.weight", K::LinearAttnA},
        {"linear_attn.out_proj.weight", K::LinearAttnOut},

8. Replace the fused-expert pass with the MLX switch-expert pass (the qwen
   second loop over `mlp.experts.*` splits `gate_up_proj`; Ornith has three
   stacked `[E, ...]` tensors instead):

```cpp
const int E = top.num_experts;
const int I = top.moe_intermediate_size;
const int H = top.hidden_size;
using ExpertKey = std::pair<int, int>;  // (layer, eid)
absl::btree_map<ExpertKey, DenseNvfp4Record> w1_map, w2_map, w3_map;
for (auto &shard : model.shards) {
    for (auto &t : shard.tensors) {
        auto p = classify_ornith_moe_tensor(t.name);
        const bool is_w1 = p.kind == OrnithMoeTensorKind::SwitchGateProj;
        const bool is_w3 = p.kind == OrnithMoeTensorKind::SwitchUpProj;
        const bool is_w2 = p.kind == OrnithMoeTensorKind::SwitchDownProj;
        if (!is_w1 && !is_w2 && !is_w3) continue;
        auto data = read_tensor_data(input_dir, shard, t);
        if (data.empty() ||
            static_cast<int64_t>(data.size()) != t.byte_size())
            return arrow::Status::IOError("failed to read tensor data: ",
                                          t.name);
        if (t.shape.size() != 3 || t.shape[0] != E)
            return arrow::Status::Invalid("bad switch_mlp shape: ", t.name);
        const int64_t rows = is_w2 ? H : I;   // w2: [E,H,I], else [E,I,H]
        const int64_t cols = is_w2 ? I : H;
        if (t.shape[1] != rows || t.shape[2] != cols)
            return arrow::Status::Invalid("switch_mlp shape mismatch: ", t.name);
        const int64_t row_bytes = cols * 2;   // BF16
        for (int e = 0; e < E; ++e) {
            DenseNvfp4Record r;
            r.name = absl::StrCat(t.name, ".e", e);
            r.shape = {rows, cols}; r.dtype = t.dtype;
            if (!quantize_slice(data.data() + static_cast<int64_t>(e) * rows * row_bytes,
                                rows * cols, r))
                return arrow::Status::IOError("quantize failed ", t.name, " e", e);
            auto &map = is_w1 ? w1_map : (is_w3 ? w3_map : w2_map);
            map[std::make_pair(p.layer, e)] = std::move(r);
        }
    }
}
for (int l = 0; l < top.num_layers; ++l) {
    for (int e = 0; e < E; ++e) {
        auto a = w1_map.find({l, e});
        auto b = w3_map.find({l, e});
        auto c = w2_map.find({l, e});
        if (a == w1_map.end() || b == w3_map.end() || c == w2_map.end())
            return arrow::Status::Invalid("missing switch_mlp half: layer ", l,
                                          " expert ", e);
        PackedExpert pe;
        pe.w1_packed = a->second.packed; pe.w1_scales = a->second.scales;
        pe.w1_shape = a->second.shape; pe.w1_global_scale = a->second.global_scale;
        pe.w3_packed = b->second.packed; pe.w3_scales = b->second.scales;
        pe.w3_shape = b->second.shape; pe.w3_global_scale = b->second.global_scale;
        pe.w2_packed = c->second.packed; pe.w2_scales = c->second.scales;
        pe.w2_shape = c->second.shape; pe.w2_global_scale = c->second.global_scale;
        ARROW_RETURN_NOT_OK(write_expert_file(base, l, e, std::move(pe)));
    }
}
```
