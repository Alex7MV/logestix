# Kimi-K2.7-Code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full-cycle integration of Kimi-K2.7-Code (DeepseekV3-style MLA + MoE, INT4-packed source experts, tiktoken tokenizer) as model id `kimi-k2.7-code` per MODEL INGEST INVARIANT.

**Architecture:** Dedicated `kimi_*` stack modeled on GLM-5.2: lsxforge converter with GPU INT4→NVFP4 dequant path, pinned zero-copy loader with expert store, MLA attention + sigmoid/noaux_tc router CUDA kernels in new OBJECT lib `lsxcommon_kimi_cu`, `KimiK27CodeModel` IModel with deterministic SelfCheck.

**Tech Stack:** C++20/C23, CUDA 13.3 (Blackwell CC 120/121), Arrow 25 IPC, Catch2 v3, spdlog via `lsxcommon::log::`, absl host-only containers.

Spec: `docs/superpowers/specs/2026-08-23-kimi-k2.7-code-ingestion-design.md`

## Global Constraints

- Branch: `feat/kimi-k2.7-code`. Never commit to `main`.
- Build/test: `cmake --build --preset linux-debug`, `ctest --preset linux-debug -R kimi`.
- Blackwell only (`120-real;121-real`); Hopper/Ada/Ampere forbidden.
- Logging only via `lsxcommon::log::*` (no cout/printf).

```cuda
#include "kimi_inference_kernels.h"
#include <cuda_bf16.h>

namespace lsxcommon { namespace kimi {

__global__ void kimi_int4_dequant_kernel(const int *__restrict__ packed,
                                         const uint16_t *__restrict__ scales,
                                         uint16_t *__restrict__ out,
                                         int cols) {
    int r = blockIdx.y;
    int c0 = (blockIdx.x * blockDim.x + threadIdx.x) * 8;
    if (c0 >= cols) return;
    int word = packed[(size_t)r * (cols >> 3) + (c0 >> 3)];
    float s = __bfloat162float(
        *reinterpret_cast<const __nv_bfloat16 *>(
            &scales[(size_t)r * (cols >> 5) + (c0 >> 5)]));
#pragma unroll
    for (int k = 0; k < 8; ++k) {
        int nib = (word >> (4 * k)) & 0xF;
        float v = static_cast<float>(nib > 7 ? nib - 16 : nib) * s;
        __nv_bfloat16 h(v);
        out[(size_t)r * cols + c0 + k] = *reinterpret_cast<uint16_t *>(&h);
    }
}

cudaError_t KimiInt4DequantToBf16(const int *d_packed, const uint16_t *d_scales,
                                  int rows, int cols, uint16_t *d_out,
                                  cudaStream_t stream) {
    dim3 block(128);
    dim3 grid((cols / 8 + block.x - 1) / block.x, rows);
    kimi_int4_dequant_kernel<<<grid, block, 0, stream>>>(d_packed, d_scales,
                                                         d_out, cols);
    return cudaGetLastError();
}

}} // namespace lsxcommon::kimi
```

Header declares it in `namespace lsxcommon { namespace kimi {` with plain
host function signature (no `__device__`).

NOTE: verify nibble order against real checkpoint semantics during Task 4
(compressed-tensors packs low nibble first within each int32 word); if the
real-model validation fails, flip to high-nibble-first and re-run this unit test.
